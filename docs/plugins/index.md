# 使用插件

插件是给桌宠加能力的小模块。有的给模型新本事（上网搜、截屏、写代码），有的在后台记东西，有的会在你空闲时主动找你说话。

## 打开插件管理

顶栏点 **插件管理**。先看 **内置插件**，再切到 **社区插件**。

![插件管理](/images/webui-plugins.png)

![社区插件](/images/webui-plugins-community.png)

每张卡片可以 **启用** 或 **禁用**。桌宠正在运行时，改开关会热加载，稍等即可；桌宠没开的话，只是把名单记下来，下次启动桌宠再生效。

## 改插件配置

卡片上的 **配置** 会打开「插件配置」窗口。按界面上的中文标题填，改完点 **保存配置**。也可以 **重置默认值**。

没有单独配置项的插件，点「打开配置」会打开插件所在的文件夹。这类插件启用即可，不必去翻目录。

每个插件要填什么、默认数字是多少，见 [内置插件](/plugins/built-in) 和 [社区插件](/plugins/community)。清单里写了秒数、毫秒的，先看那个数字再决定要不要改弹窗；只有文件路径和端口才是「没搬家就不用动」。

## 让模型真的去用工具

到 [基础配置](/config/basic) 打开 **启用 Function Call 工具**。关掉的话，插件即使启用了，模型也调不到搜索、截图、写代码这类能力。

## 从广场安装

顶栏 **广场工具屋 → 插件广场**。要联网。点安装，等它下完。

![插件广场](/images/webui-market-plugin.png)

装成功后，回到插件管理的 **社区插件** 列表，再启用。广场上那些本仓库没有源码的插件，配置以它们自己的弹窗为准，本站不逐个写。

想自己做插件，看 [制作插件](/plugins/develop)。

## 安装里默认已经打开的

下面这 7 个随安装就启用了：

- [代码执行](/plugins/built-in#代码执行)
- [MemOS 长期记忆](/plugins/built-in#memos-长期记忆)
- [思痕之册](/plugins/built-in#思痕之册)
- [网络搜索](/plugins/built-in#网络搜索)
- [核心记忆注入](/plugins/community#核心记忆注入)
- [用户画像](/plugins/community#用户画像)
- [晨昏之线](/plugins/community#晨昏之线)

**网络搜索** 仍要自己去 [Tavily](https://tavily.com) 申请 Key 填进配置弹窗，否则等于开了个空开关。

## 开完之后说话变了样

插件可能会往提示词里注入时间、记忆、屏幕说明。先回 [人设](/config/persona) 看一眼，再决定是留下还是关掉那个插件。

回到 [控制面板一览](/config/panel) 或 [快速开始](/guide/quick-start)。
