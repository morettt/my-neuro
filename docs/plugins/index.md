# 使用插件

插件的安装、启用、配置，以及常见内置插件的说明，会在后续版本写进本站。

## 现在能做什么

- 在 WebUI 的 **插件管理** 页查看已安装插件，逐个启用或停用
- 在 **广场工具屋 → 插件广场** 浏览社区插件
- 想自己动手的话，仓库里的 `live-2d/plugins/README.md` 有 SDK 说明

![插件管理](/images/webui-plugins.png)

![插件广场](/images/webui-market-plugin.png)

::: tip
插件可能会改人设提示词或往对话里加工具说明。开完插件后角色说话变了样，先回 [人设](/config/persona) 看一眼。
:::

回到 [控制面板一览](/config/panel) 或 [快速开始](/guide/quick-start)。
