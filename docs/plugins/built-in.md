# 内置插件

这些随安装带上，在插件管理的 **内置插件** 子页签里开关。按下面分组找即可，不必从头读到尾。

怎么启用、怎么打开配置弹窗，见 [使用插件](/plugins/)。仓库自带的社区插件在 [社区插件](/plugins/community)。

## 给模型用的电脑工具（不用配）

### 截图

让模型截取当前屏幕再看。适合问「我屏幕上这是什么」「帮我看一下这个窗口」。

主模型不能看图时，还要在 [基础配置](/config/basic) 打开辅助视觉模型。

插件管理里启用即可，没有单独配置项。

### 自动打字

让模型在当前输入焦点模拟打字，相当于替你往正在编辑的地方敲字。焦点要先点在目标窗口里。

插件管理里启用即可，没有单独配置项。

### 键盘控制

让模型按方向键（上、下、左、右），用来挪选中项或简单操作界面。

插件管理里启用即可，没有单独配置项。

### 鼠标点击

让模型点击鼠标**当前所在位置**。它点的是光标现在停的地方，不会自己找按钮坐标。

插件管理里启用即可，没有单独配置项。

### 等待

让模型先停几秒再继续，例如等网页加载。单次最多约 10 秒。

插件管理里启用即可，没有单独配置项。

### 打开网页

用系统默认浏览器打开一个网址。

插件管理里启用即可，没有单独配置项。

### 代码执行

让模型在本机 Python 环境里跑代码、装包。安装时默认已经启用。

这是真的在你电脑上执行，不要对不可信的对话开着不管。

插件管理里启用即可，没有单独配置项。

### 音效播放

让模型在说话时配上短音效（吃惊、爆炸、OMG 一类），对话会热闹一点。

插件管理里启用即可，没有单独配置项。

## 要准备 Key 或外置程序

### 网络搜索

让桌宠上网查资料，再根据结果回答。安装时默认已经启用，但没 Key 就搜不成。

#### 用之前要准备什么

到 [Tavily](https://tavily.com) 申请 API Key。用你自己的，不要借用别人的。

到 [基础配置](/config/basic) 打开 **启用 Function Call 工具**。

#### 在插件配置里填什么

| 界面标题 | 填什么 | 不填会怎样 | 默认 |
| --- | --- | --- | --- |
| Tavily API Key | 你自己申请的 Key | 模型一搜就会失败 | 空 |

#### 怎么知道生效了

问一个今天才发生、模型不可能靠训练数据答准的问题。它会先去搜，再把结果说给你听。

### PC 屏幕控制

让模型先「看」屏幕上的元素，再移动鼠标去点。这是真点击，点错窗口会动到你正在用的程序。

#### 用之前要准备什么

准备一个能看图的视觉模型账号和 Key。弹窗默认按硅基流动的地址和 Qwen2.5-VL 模型名来填，你仍要自备 Key；换提供商就把地址和模型名改成控制台里的。

到 [基础配置](/config/basic) 打开 **启用 Function Call 工具**。

#### 在插件配置里填什么

| 界面标题 | 填什么 | 不填会怎样 | 默认 |
| --- | --- | --- | --- |
| 视觉模型 API Key | 该提供商的 Key | 点屏幕会失败 | 空 |
| 视觉模型 API URL | 该提供商兼容 OpenAI 的接口地址 | 走默认硅基流动地址 | `https://api.siliconflow.cn/v1` |
| 视觉模型名称 | 控制台里的视觉模型 ID | 用默认的 Qwen2.5-VL | `Qwen/Qwen2.5-VL-72B-Instruct` |

#### 怎么知道生效了

让桌宠点桌面上某个按钮或图标。光标应移过去并点一下。

### 音乐播放

让角色按歌曲库演唱：随机一首、指定文件名、列出曲目、停止。

歌曲文件放在桌宠目录下的 `song-library/output`，支持 `.mp3`、`.wav`、`.m4a`、`.ogg`。还要本机的音乐控制服务在跑。控制服务默认端口 **3001**，没改过音乐服务端口就不用动这项。文件夹是空的，或服务没起来，唱歌会失败，跟端口无关。

### Minecraft 游戏集成

把你对桌宠说的话转给本机的 Mindcraft 机器人，让它在《我的世界》里走动、挖掘、建造。本插件不负责安装游戏或 Mindcraft，只负责对接。

#### 用之前要准备什么

1. 按 Mindcraft 自己的说明，把游戏和机器人跑起来。
2. 记下机器人在 Mindcraft 里的名字（和它配置文件里的 name 一致）。
3. 准备一份给机器人用的、兼容 OpenAI 的模型 Key。

#### 在插件配置里填什么

| 界面标题 | 填什么 | 不填会怎样 | 默认 |
| --- | --- | --- | --- |
| Mindcraft 服务器地址 | 你的 Mindcraft 地址 | 去连本机 `8080` | `http://localhost:8080` |
| 机器人名称 | 与 Mindcraft 里机器人的名字一致 | 对不上就转不进去 | `fake-neuro` |
| API KEY | 给机器人用的 Key | 游戏侧调模型失败 | 空 |
| 模型名称 | 这份 Key 能用的模型 ID | 用弹窗默认名，可能和你的提供商对不上 | `gemini-2.0-flash` |
| 模型 URL | 你的提供商接口地址 | 走弹窗里的示例地址，可能不可用 | 填你自己的提供商地址 |
| 对话设定 | 机器人在游戏里的说话风格 | 用你保存在弹窗里的内容 | 弹窗里已有一份示例 |

#### 怎么知道生效了

对着桌宠说一句游戏里的指令，例如去某个玩家旁边。游戏里的机器人应跟着动，而不是只在桌面上口头答应。

### RAG 记忆检索

让模型向本机 RAG 服务查历史对话和资料。前置是在 [启动服务](/config/start-services) 把 **RAG** 拉起来。地址默认是 `http://127.0.0.1:8002/ask`。启动页 RAG 能起来、你没改过端口，就不用动弹窗。

## 记忆与日记

### MemOS 长期记忆

跨会话的长期记忆。你说话时，它会自动找出相关记忆塞进提示词；隔几轮再把对话存进记忆库。模型也可以主动补一条、搜旧记忆、存图片、导入网页或文档、改写记错的内容。

安装时默认已经启用。

#### 用之前要准备什么

1. 在 [启动服务](/config/start-services) 把 **记忆系统** 启到可用（端口 `8003`）。启动页没有这张卡时，对照 [介绍](/guide/introduction)，不假装一定有。
2. 主对话模型已经能聊。弹窗里「后端 LLM」三项留空时，会回落到你正在用的主 LLM。

记忆系统怎么启动、连不上时对话会怎样，见 [基础配置](/config/basic)，这里不重复部署步骤。

#### 在插件配置里填什么

| 界面标题 | 填什么 | 不填会怎样 | 默认 |
| --- | --- | --- | --- |
| 启用 MemOS | 保持打开 | 关了就完全不记 | 开 |
| MemOS API 地址 | 与启动页记忆系统一致 | 连错端口就注入失败 | `http://127.0.0.1:8003` |

其余常见项：自动注入默认开，每次注入 **3** 条；相似度阈值出厂 **0.6**（你弹窗里若显示 0.5，以屏幕为准）；每 **5** 轮存一次对话。后端 LLM 三项留空就用主模型；备用 LLM 默认关；BM25、知识图谱、图片记忆默认开。精排默认关，低配机器不要打开。

#### 怎么知道生效了

隔天再提昨天说过的一件具体事，角色能想起来；或者明确说「记住这个，以后都要记得」，下一轮还能对上。

### 用户记忆

让模型把个人信息、偏好记到一份本地 JSON 里，之后可以读、搜、删。这和 MemOS 不是同一套：一个是文件备忘，一个是向量长期记忆。

默认文件名是 **用户记忆.json**（程序根目录）。没搬家、也不想换文件，就不用动这项。

### 日程管理

让模型添加、查看、完成、修改、删除日程。数据存在本地 JSON 里，关掉程序再开还在。

默认路径是 **AI记录室/日程表.json**。没搬家就不用动。

### AI 日记

你一段时间不说话，角色会以自己的口吻写一篇短日记，存到 AI 记录室。

弹窗里「写日记触发时间」的单位是**毫秒**，默认 **20000**，也就是闲置 **20 秒** 就开始写。开着会很快动笔。想等你离开再写，改成 `300000`（5 分钟）或更大。日记默认写到 `AI记录室/AI日记.txt`。提示词默认是肥牛口吻，换角色再改「日记提示词」。

不要和 [自动对话模块](#自动对话模块)、[心情对话系统](#心情对话系统)、[定时问候](/plugins/community#定时问候) 一起开着不管，几套会抢着找你说话。

### 思痕之册

晚上你说「晚安」「我去睡了」这类话时，把当天对话收成一篇观察日志，也可以再做成月度总结，并写入核心记忆。你也可以直接让它「写 AI 日志」。

安装时默认已经启用。自动写日志的窗口默认是晚上 **21 点** 到凌晨 **7 点**；想更早或更晚，改「日志触发时间」。API 地址、Key、模型三项留空就用正在聊的主 LLM，这三项可以不管。

### 上下文压缩

对话历史太长时，自动把旧消息收成摘要，省 token。默认超过 **16** 条就压，留下最近 **4** 条。对话很长仍觉得它忘事，把「压缩触发阈值」调大；觉得上下文太肥，维持或调小。

## 主动找你说话

### 自动对话模块

你一段时间不说话，桌宠会按刚才的上下文主动接一句。启用后默认空闲 **15 秒** 就开口，会一直来接话。想当桌宠陪着但不想被催，把「空闲触发时间」改成 60～180 秒。

不要和 [心情对话系统](#心情对话系统)、[定时问候](/plugins/community#定时问候) 一起开，几套会抢着说话。

### 心情对话系统

给角色一个心情分数，分数高就更勤快地找你说话，分数低就少开口，沉默时干脆不主动。心情会随你回不回它慢慢变。

默认间隔：兴奋每 **5 秒**、普通 **30 秒**、低落 **60 秒**，沉默不说。心情高时 **5 秒** 开口一次，会非常密。想留着主动聊天，至少把「兴奋状态间隔」改大（例如 30）。阈值和心情加减可以先不动。

不要和 [自动对话模块](#自动对话模块)、[定时问候](/plugins/community#定时问候) 一起开，几套会抢着说话。

## 直播与翻译

### B站直播弹幕

监听一个 B 站直播间的弹幕，读到就让桌宠回应。默认房间号是别人的，不改就等于去听一个你不认识的直播间。

不要和 [智能弹幕过滤](/plugins/community#智能弹幕过滤) 一起开：两套会各自去拉同一个接口，容易重复回复。

#### 用之前要准备什么

准备你的直播间**房间号**（直播间网址里那串数字）。不要把它和主页 UID 混成同一个数，填错就听不到弹幕。

#### 在插件配置里填什么

| 界面标题 | 填什么 | 不填会怎样 | 默认 |
| --- | --- | --- | --- |
| 直播间 ID | 你自己的房间号 | 会去听默认的别人的房间 | `30230160` |

房间号必须改成你自己的。拉取间隔默认 **5 秒**，接口是 B 站公开弹幕接口；没遇到限流，这两项不用动。

#### 怎么知道生效了

开播后房间里出现弹幕，桌宠会读出来并回应。

### 同声传译

送进语音合成的文本会被译成目标语言，字幕仍保持原文。默认是把中文译成英语。

#### 用之前要准备什么

主 LLM 已经能聊即可。要译成英语以外的语言，必须改提示词。

#### 在插件配置里填什么

| 界面标题 | 填什么 | 不填会怎样 | 默认 |
| --- | --- | --- | --- |
| 翻译系统提示词 | 写明目标语言，并要求只返回译文 | 会按默认译成英语 | 你是一个专业翻译助手，请将以下中文准确翻译成英语，保持原意和语调，只返回翻译结果，不要添加任何解释： |
| 翻译 API Key | 想用独立翻译模型时再填 | 留空则用主 LLM | 空 |
| 翻译 API 地址 | 同上 | 留空则用主 LLM | 空 |
| 翻译模型 | 同上 | 留空则用主 LLM | 空 |

Key、地址、模型三项都留空时，翻译走你正在用的对话模型。

#### 怎么知道生效了

角色嘴里是外语，字幕仍是中文（或你原来的原文）。
