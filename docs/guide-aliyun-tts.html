阿里云 TTS 部署教程

📦 my-neuro v6.6 线上版 ☁️ 阿里云百炼 CosyVoice 📅 2026-07-03

让肥牛开口说话——无需显卡、不用启动 2.TTS.bat，配置好 API Key 和音色即可。

一、概述

my-neuro 线上版内置 阿里云百炼 CosyVoice 语音合成。启用后，AI 的语音通过云端实时合成，不需要在本机运行本地 GPT-SoVITS。

项目说明
云服务阿里云百炼（DashScope）
默认模型cosyvoice-v3-flash
通信方式WebSocket 流式合成
配置文件live-2d/config.json → cloud.aliyun_tts
图形化配置WebUI → 云端配置 → 阿里云 TTS

二、你需要准备什么

  1. 阿里云账号（需完成实名认证）
  2. 百炼 API Key（格式 sk-xxxxxxxx）
  3. 音色 ID——系统预设音色 或 声音复刻音色（二选一）
  4. 网络——能访问 dashscope.aliyuncs.com

三、开通百炼并获取 API Key

步骤 1：进入百炼控制台

  1. 打开 阿里云百炼控制台
  2. 首次使用需开通「大模型服务平台百炼」

步骤 2：创建 API Key

  1. 找到 API-KEY 管理
  2. 点击 创建 API Key
  3. 选择地域：华北2（北京）（my-neuro 默认连接北京节点）
  4. 复制以 sk- 开头的 Key，妥善保存
注意： 北京与新加坡的 API Key 不通用。本教程默认使用北京地域。

官方文档：获取 API Key

四、获取音色 ID

方式 A：系统预设音色（推荐新手）

无需上传音频，开箱即用。

  1. 打开 CosyVoice 音色列表（官方）
  2. 在 CosyVoice-v3-Flash 分类下选择音色
  3. 复制 voice 参数 作为声音 ID
音色名称声音 ID特点
龙安洋longanyang阳光大男孩，普通话 + 英文
龙安欢longanhuan欢脱元气女
龙安欢（V3）longanhuan_v3支持多种方言
龙呼呼longhuhu_v3童声
模型名填 cosyvoice-v3-flash，声音 ID 填上表参数即可。

方式 B：声音复刻（克隆专属声线）

适合复刻特定人物、虚拟角色声音。

1. 准备参考音频

要求说明
格式WAV（16bit）、MP3、M4A
时长推荐 10~20 秒，最长 60 秒
大小≤ 10 MB
内容清晰人声，无背景音乐、无噪音

2. 上传音频到公网 URL

常见做法：上传到 阿里云 OSS 并设置公共读，或使用其他可公网下载的链接。

3. 调用 API 创建音色

在 PowerShell 或 CMD 中执行（请替换占位符）：

powershell 
curl -X POST "https://dashscope.aliyuncs.com/api/v1/services/audio/tts/customization" ^
  -H "Authorization: Bearer sk-你的API_KEY" ^
  -H "Content-Type: application/json" ^
  -d "{\"model\":\"voice-enrollment\",\"input\":{\"action\":\"create_voice\",\"target_model\":\"cosyvoice-v3-flash\",\"prefix\":\"myvoice\",\"url\":\"https://你的音频公网地址.wav\",\"language_hints\":[\"zh\"]}}"
参数说明
target_model必须与 my-neuro 中模型名一致，推荐 cosyvoice-v3-flash
prefix音色前缀（英文字母/数字，≤ 10 字符）
url参考音频公网 URL

4. 获取 voice_id

成功后响应中包含 voice_id，格式类似：

示例 
cosyvoice-v3-flash-myvoice-xxxxxxxxxxxxxxxx
重要： 创建时的 target_model 必须与合成时的模型 完全一致，否则合成失败。

五、在 my-neuro 中配置

方式 1：通过 WebUI（推荐）

  1. 进入 live-2d，双击 启动 WebUI 控制面板.bat
  2. 打开 云端配置 → 阿里云 TTS
  3. 勾选启用，填写 API Key、模型名、声音 ID
  4. 点击 保存配置
配置项填写内容
启用阿里云 TTS✅ 勾选
API KEY百炼 API Key（sk-...）
模型名cosyvoice-v3-flash
声音 ID系统音色或复刻 voice_id

同时请确认以下项 不要勾选：

  • 字节 TTS（火山引擎）
  • 云端 TTS（SiliconFlow 等）
  • 云端肥牛 · 启动全云端（已弃用，不可用）
注意： WebUI 里可能仍能看到「云端肥牛」「RAG 服务」等旧入口，均已弃用，请勿启用或启动。
TTS 优先级：字节 TTS → 阿里云 TTS → 云端 TTS → 本地 TTS。多个同时启用时，只有优先级最高的生效。

方式 2：编辑 config.json

打开 live-2d/config.json，修改 cloud.aliyun_tts：

json 
"aliyun_tts": {
  "enabled": true,
  "api_key": "sk-你的API_KEY",
  "model": "cosyvoice-v3-flash",
  "voice": "longanyang",
  "sample_rate": 48000,
  "volume": 50,
  "rate": 1,
  "pitch": 1
}

高级参数（仅 config.json，WebUI 暂不支持）：

参数默认说明
sample_rate48000采样率 Hz
volume50音量 0~100
rate1语速 0.5~2.0
pitch1音调 0.5~2.0

六、启动与验证

启动 my-neuro

在 WebUI 服务控制 中，按顺序启动：

  1. ASR 语音识别
  2. 记忆系统（MemOS） — 线上版 必做
  3. Live2D 主服务

无需启动 2.TTS.bat（本地 GPT-SoVITS）。详细启动说明见 使用教程。

验证是否生效

  1. 与 AI 对话，观察是否有语音输出
  2. 查看 WebUI 桌宠日志，失败时会看到类似 阿里云TTS失败 的报错

常见失败原因

现象可能原因解决方法
无声音，task-failedAPI Key 错误重新创建并更新配置
voice 相关错误声音 ID 与模型不匹配确认 target_model 一致
仍走本地 TTS其他 TTS 同时启用关闭字节/云端 TTS
WebSocket 失败网络问题检查防火墙、代理、DNS
复刻音色失败1 年未使用被清理重新创建音色
余额不足账户欠费阿里云控制台充值

七、费用说明

项目费用
CosyVoice 声音复刻免费
CosyVoice 语音合成按调用量计费
系统预设音色按合成单价计费

新用户通常有免费额度，详见 百炼定价。

八、与本地 TTS 的对比

对比项阿里云 TTS本地 GPT-SoVITS
显卡不需要需要 NVIDIA 显卡
启动只需配置 Key需先启动 TTS 服务
声音定制声音复刻 API本地训练
延迟依赖网络本地通常更低
费用按量付费免费（自备硬件）

十、完整配置示例

json 
{
  "tts": {
    "enabled": true,
    "url": "http://127.0.0.1:5000",
    "language": "zh"
  },
  "cloud": {
    "volcengine_tts": { "enabled": false },
    "aliyun_tts": {
      "enabled": true,
      "api_key": "sk-你的API_KEY",
      "model": "cosyvoice-v3-flash",
      "voice": "longanyang",
      "sample_rate": 48000,
      "volume": 50,
      "rate": 1,
      "pitch": 1
    },
    "tts": { "enabled": false }
  }
}
tts.enabled 保持 true 表示启用语音输出；实际合成引擎由 cloud.aliyun_tts.enabled 决定。
