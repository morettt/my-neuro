# 快速开始

让桌宠出现并回答一句。这一页只给能跑通的最小配置，每一项的完整说明都链到后面的配置页。

## 你需要先有的东西

- 已解压的 my-neuro 安装目录（路径不要有中文、空格、括号）
- 一个 **OpenAI 兼容** 的大模型 API（Key、地址、模型名）
- 想用麦克风说话的话，还需要一个能用的麦克风

## 最省事的一条路：打字聊天 + 云端发音

这条路不需要显卡、不需要本地模型，六步跑完。想用麦克风或本地声音，看下一节。

### 1. 打开 WebUI

进入安装目录下的 `live-2d`，双击 **`启动 WebUI 控制面板.bat`**。浏览器会打开 **My Neuro - 控制中心**。

浏览器没自动打开时，看黑色窗口里的 `http://localhost:端口`，复制到浏览器。确认你看到的是网页控制中心，不是 `肥牛.exe`。

![控制中心启动页](/images/webui-home.png)

### 2. 填聊天模型

打开 **LLM 配置** → 点左侧 **添加** → 填 API Key 和 API URL → 点 **从 API 获取** 拉出模型列表 → 点右上角 **保存配置**。

推荐 [RabbitAPI](https://rabbitapi.online/)（**需要梯子**）；硅基流动等国内 OpenAI 兼容接口也可以。逐步截图见 [LLM 提供商](/config/llm)。

### 3. 选对话模型，打开输入框

打开 **功能配置**：在「对话模型」里选刚才那个模型，勾上「文字输入框」，点 **保存配置**。

### 4. 配一种云端发音

打开 **云端配置** → 子页 **阿里云 TTS** → 勾「启用」并填 API Key 和音色 → 点 **保存配置**。

字节 TTS 和「云端 TTS」保持关闭。同时开多种时，只有优先级最高的那个会生效，详见 [怎么说](/config/speak)。

### 5. 启动桌宠

回到 **启动** 页，点 **Live2D 主服务** 的「启动」。桌面上应该出现角色。

### 6. 打一句话

在桌宠的输入框里打字回车。听到回复或看到字幕，就算跑通了。

## 想用语音输入或本地发音

前两步（打开 WebUI、填聊天模型）完全一样，区别在听和说这两侧。

**用麦克风说话**，二选一：

- **本地 ASR**：功能配置勾「启用 ASR」，再到启动页点 ASR 的「启动」，等状态点变绿（端口 `1000`）。
- **百度流式 ASR**：功能配置勾「启用 ASR」，再到云端配置的「百度流式 ASR」填 Key。不占本地端口。

**用本地声音发音**（需要装过 TTS 模型）：功能配置勾「启用 TTS」，把云端配置里那几种 TTS 全部关掉，再到启动页点 TTS 的「启动」（端口 `5000`）。

启动页上看不到 ASR / TTS 卡片，说明这份安装没有本地语音模型，对照见 [介绍](/guide/introduction)。

完整选项见 [怎么听](/config/listen) 和 [怎么说](/config/speak)。

## 服务和桌宠的启动顺序

启动页上有 **一键启动**，它会依次拉起 ASR、TTS、记忆系统、RAG、BERT，等端口就绪后再开 Live2D。缺模型时会在日志里报失败。

若 Live2D 的「启动」按钮暂时点不动、提示等待端口，说明你点过那些服务但端口还没起来。等到绿灯，或等约 90 秒超时后再点。没启动过那些服务时不会被拦住。

详见 [启动服务](/config/start-services)。
