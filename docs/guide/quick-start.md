# 快速开始

用最短路径让桌宠出现并回答一句。细节都链到后面的配置页，这里不展开所有选项。

## 你需要先有的东西

- 已解压的 my-neuro 安装目录（路径不要有中文、空格、括号）
- 一个 **OpenAI 兼容** 的大模型 API（Key、地址、模型名）
- 想用语音的话：麦克风，以及下面「听 / 说」各选一种

## 1. 打开 WebUI

1. 进入安装目录下的 `live-2d` 文件夹。
2. 双击 **`启动 WebUI 控制面板.bat`**。
3. 浏览器应打开 **My Neuro 控制中心**。有本地 TTS 模型时，「启动」页会看到 ASR / TTS 等卡片；没有时这些卡片和「声音克隆」页会藏起来。

浏览器没自动打开时，看黑色窗口里的 `http://localhost:端口`，复制到浏览器。

确认你看到的是网页控制中心，不是 `肥牛.exe`。对照见 [打开 WebUI](/config/open-webui)。

![控制中心启动页](/images/webui-home.png)

## 2. 配好聊天模型

1. 打开 **LLM 配置**。
2. 添加一个提供商：填 API Key、API URL。
3. 用「从 API 获取」或手动「添加模型」。
4. 点右上角 **保存**。
5. 打开 **功能配置**，在「对话模型」里选出刚加的模型，再保存。

逐步截图见 [LLM 提供商](/config/llm)。推荐 [RabbitAPI](https://rabbitapi.online/)（**需要梯子**）；硅基流动等国内 OpenAI 兼容接口也可以。

## 3. 选怎么听、怎么说

两者独立，组合随便，但 **TTS 只启用一种**。

推荐新手组合：

- 有本地 ASR 服务：功能配置里保持「启用 ASR」，「启动」页里启动 **ASR 语音识别**。
- 没有本地 TTS 模型（「启动」页看不到 TTS 卡片），或你不想占显卡：到 **云端配置** 启用 **阿里云 TTS** 或 **字节 TTS** 或「云端 TTS」，填好 Key。
- 两种都有本地模型：「启动」页里启动 ASR 和 TTS，云端页那些 TTS 开关先关掉。

边界说明见 [怎么听](/config/listen) 和 [怎么说](/config/speak)。

## 4. 启动该启的服务，再开桌宠

打开 **启动** 页：

1. 你用了本地 ASR，就点 ASR **启动**，等状态变绿（端口 `1000`）。
2. 你用了本地 TTS，就点 TTS **启动**，等变绿（端口 `5000`）。
3. 若界面上有 **记忆系统**，建议启动（端口 `8003`）。一键启动会尝试拉起 ASR / TTS / 记忆 / RAG / BERT，缺模型时报错可以看日志，不要假装成功。
4. 点 **Live2D 主服务 → 启动**。

若按钮提示「等待 ASR / TTS / 记忆系统 端口响应」，说明你点过启动但端口还没起来。等到绿灯，或等约 90 秒超时后允许手动再点。没有点过那些服务时，一般不会被拦住。

成功后桌面上出现角色。

## 5. 说一句或打一句

- 语音：对着麦克风说话（ASR 已启用且对应服务在跑，或已启用百度流式 ASR）。
- 打字：功能配置勾选「文字输入框」，保存后重启桌宠。

打断正在说的话：`Ctrl + G`。

到这里如果能听到回复或看到字幕，快速开始就结束了。接着可以改 [人设](/config/persona) 和 [Live2D](/config/live2d)。
