# 三份文档怎么选

my-neuro 现在同时存在三套给用户看的说明。先看你打开的是哪一个窗口，再点对应入口。

| 你正在用的东西 | 该看哪份 |
| --- | --- |
| 浏览器「My Neuro - 控制中心」，顶栏是启动、基础配置、LLM 配置、云端配置 | **本站（WebUI 文档）** |
| 桌面上的 **肥牛.exe**，左侧栏是启动、LLM配置、终端控制室 | [肥牛.exe 教程](/qt/) |
| 安装包怎么下、更旧的箭头截图 | [官网教程](http://mynewbot.com/tutorials) |

官网会继续保留下载和旧图。项目 README 里也可以同时给出这些入口。

## WebUI 文档（本站）

适用对象：

- 用 `live-2d/启动 WebUI 控制面板.bat` 打开浏览器
- 页面标题是 **My Neuro - 控制中心**
- 顶栏页签是 **启动、基础配置、功能配置、人格设置、LLM 配置、云端配置、Live2D设置、广场工具屋、插件管理**（装了本地 TTS 模型时还多一个 **声音克隆**）

本站所有截图和按钮名称都以这套界面为准。听和说可以混用，不按「云端教程 / 本地教程」分册。

## 肥牛.exe 教程

地址：[肥牛.exe 教程](/qt/)

适用对象：

- 双击 `live-2d/肥牛.exe` 打开的桌面窗口
- 窗口标题类似 **My-Neuro (本地)**
- 保存按钮写的是 **更新配置**，启动角色写的是 **启动桌宠**

那一份教程的截图全部来自 exe 窗口，不要用本站 WebUI 截图去对按钮。

## 官网

地址：[http://mynewbot.com/tutorials](http://mynewbot.com/tutorials)

负责安装包怎么选、怎么解压，以及更旧的标签和箭头图。已经解压好、准备点按钮时，按你打开的是浏览器还是 exe，选上面两行。

::: warning 两边的填法不一样
最容易搞混的是 LLM。WebUI 里是「多个提供商，每个提供商一份模型列表」，再到功能配置里挑这次用哪个模型，保存按钮是 **保存配置**。

肥牛.exe 是同一页四个框：API KEY、API URL、模型名称、AI人设，改完点 **更新配置**。

不要把网页教程里的按钮名拿到 exe 里找「长得像的」去点。
:::

交流群：WebUI 文档写的是 **518300858**；肥牛.exe 手册里写的是 **756741478**。两个都保留，不合并。
