# 本站与官网旧教程

my-neuro 现在同时存在两套给用户看的说明，用途不同。

## WebUI 文档（本站）

适用对象：

- 用 `live-2d/启动 WebUI 控制面板.bat` 打开浏览器
- 页面标题是 **My Neuro - 控制中心**
- 顶栏页签是 **启动、基础配置、功能配置、人格设置、LLM 配置、云端配置、Live2D设置、广场工具屋、插件管理**（装了本地 TTS 模型时还多一个 **声音克隆**）

本站所有截图和按钮名称都以这套界面为准。听和说可以混用，不按「云端教程 / 本地教程」分册。

## 官网旧教程

地址：[http://mynewbot.com/tutorials](http://mynewbot.com/tutorials)

适用对象：

- `肥牛.exe`
- 官网里按旧标签、旧箭头截图写的步骤

官网教程会继续保留。项目 README 里同时给出两套入口。

::: warning 两边的填法不一样
最容易搞混的是 LLM。WebUI 里是「多个提供商，每个提供商一份模型列表」，再到功能配置里挑这次用哪个模型；官网旧界面是几个输入框填完就结束。跟着本站截图对照控件最稳。
:::
