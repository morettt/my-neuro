# 本站与官网旧教程

my-neuro 现在同时存在两套给用户看的说明，用途不同。

## WebUI 文档（本站）

适用对象：

- 用 `live-2d/启动 WebUI 控制面板.bat` 打开浏览器
- 页面标题类似 **My Neuro 控制中心**
- 顶栏页签是 **启动、基础配置、功能配置、人格设置、LLM 配置、云端配置、Live2D设置、广场工具屋、插件管理**（有本地 TTS 模型时还有 **声音克隆**）

本站所有截图和按钮名称都以这套界面为准。听和说可以混用，不按「云端教程 / 本地教程」分册。

## 官网旧教程

地址：[http://mynewbot.com/tutorials](http://mynewbot.com/tutorials)

适用对象：

- `肥牛.exe`
- 官网里按旧标签、旧箭头截图写的步骤

官网会继续保留，本任务也不会去改那个网站。两套入口在项目 README 里都会放。

::: warning
不要把官网截图里的按钮，拿到 WebUI 里找「长得像的」乱点。LLM 在 WebUI 里已经是「多提供商 + 模型列表」，不是旧文常见的三个框单独一页就结束。
:::

## 仓库里曾经的本地 HTML 教程

安装包里以前还有 `docs/guide-usage.html` 等静态页，以及根目录的 `线上版本使用教程.md`。那些是给早期线上包看的说明书，和当前 WebUI 已经对不齐。本站取代仓库内那一套网页；**官网仍单独保留**。
