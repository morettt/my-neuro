## 什么是 my-neuro

my-neuro（社区常叫「肥牛」）是一个跑在 Windows 桌面上的 AI 虚拟伙伴。你可以说话或打字跟它聊，它会调用大模型思考，再用语音念出来，并驱动皮套做表情和动作。

本站沿用两个社区叫法：**皮套**指角色形象，也就是 Live2D / VRM / MMD / PNGTuber 这类模型；**桌宠**指启动后出现在桌面上的那个角色窗口。

它不是又一个网页聊天框。目标是把角色的声音、性格、形象放在你自己的电脑上，用工作台的方式一点点调成你想要的样子。项目受 Neuro-sama 启发，默认角色叫肥牛。

源码与发行包见 [GitHub morettt/my-neuro](https://github.com/morettt/my-neuro)。

## 和普通聊天机器人差在哪

常见聊天机器人是「一句进、一句出」。my-neuro 把一条对话拆成几段本地或云端能力，再拼回桌面上的角色：

```
你说话或打字
    → 听（本地 ASR，或百度等云端 ASR）
    → 思考（你配置的 LLM API）
    → 说（本地 GPT-SoVITS，或阿里云 / 字节 / 其他云端 TTS）
    → 皮套做表情、出字幕
```

听和说是两套独立开关，可以混用。例如电脑有麦克风和本地识别，但没有 TTS 模型，就可以搭成 **本地 ASR + 阿里云 TTS**。

## 有没有本地 TTS，界面会不一样

判断标准是安装目录里 `full-hub/tts-hub` 下有没有模型子目录。这一条决定了控制面板上能看到哪些入口，本站其他页面提到「界面不一样」时都是指这里：

- **装了本地 TTS**：启动页上能看到 ASR、TTS、记忆系统、RAG、BERT 这些服务卡片，顶栏还多一个「声音克隆」页。
- **没装**：启动页只剩「Live2D 主服务」一张卡，「声音克隆」不出现。切到经典版面时，标题里会多出 **（云端）** 字样。

这不是两套产品，同一个界面按你装了什么显示。没装本地 TTS 也能语音聊天：到「云端配置」里启用一种云端 TTS，听的一侧仍然可以用本地 ASR。

## 核心特性（WebUI 里能管到的）

- **语音与打字**：默认可以对着麦克风说；也可以打开文字输入框。
- **实时打断**：说话或 `Ctrl + G` 打断正在播放的语音。
- **多提供商 LLM**：OpenAI 兼容接口；对话模型和视觉模型分开选。
- **皮套**：Live2D、VRM、MMD、PNGTuber；动作与表情绑定；AI 编舞与传统动作。
- **记忆**：MemOS 长期记忆（服务端口 `8003`）。
- **视觉**：每次对话截屏，或用 BERT 判断要不要截屏。
- **工具**：Function Call 与 MCP。
- **插件**：内置 / 社区 / 广场工具屋。

更完整的功能清单在项目 [README](https://github.com/morettt/my-neuro/blob/main/README.md)。本站只保证 **WebUI 操作路径** 和当前上游界面一致。
