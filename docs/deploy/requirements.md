# 环境要求

官方安装包只提供 **Windows** 版本，本站的步骤也按 Windows 写。

## 系统

- Windows 10 或 Windows 11
- 安装路径、用户名路径尽量只用英文，**不要包含中文、空格、括号**

## 硬件（按你启用的组件）

| 你打算启用的能力 | 建议 |
| --- | --- |
| 只聊天（打字）+ 云端发音 | 普通电脑即可，需要稳定网络 |
| 本地 ASR（`1.ASR.bat`，端口 1000） | 内存建议 16 GB；麦克风 |
| 本地 TTS（`2.TTS.bat`，GPT-SoVITS，端口 5000） | NVIDIA 显卡。安装器确认页会检测可用显存，低于约 5 GB 时不允许继续装 TTS 相关组件 |
| MemOS 记忆 | 第一次启动要加载 Embedding 模型，可能要等 1～3 分钟 |
| BERT 智能截图 | 额外本地模型，安装器里可选 |

没装本地 TTS 时，启动页上不会出现 TTS 卡片，「声音克隆」页也不显示。只要安装器勾过 ASR、并且启动页上有 ASR 卡片，本地识别仍然可用。这套显示规则见 [介绍](/guide/introduction)。

## 账号与网络

- 聊天：**任意 OpenAI 兼容 API**。推荐 [RabbitAPI](https://rabbitapi.online/)（访问和调用都要开梯子）；也可用硅基流动、自建 vLLM 等
- 云端发音（可选）：阿里云百炼、火山引擎字节 TTS，或其他「云端 TTS」提供商（界面默认填的是 SiliconFlow 地址）
- 云端识别（可选）：百度流式 ASR
- 「启动全云端 / 云端肥牛」：界面上有开关和密钥栏，需要官网发放的网关地址与 Key。能否连通看保存后的桌宠日志；它和其他 TTS 同时只能开一个

## 软件环境（整合包通常已带）

整合包会带 `env\python.exe` 和 `live-2d\node`。从源码自己搭时才需要系统 Python、Node.js、conda 环境 `my-neuro`。本站默认你用的是发行安装包，而不是开发者源码树。
