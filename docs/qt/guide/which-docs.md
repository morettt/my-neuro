# 三份文档怎么选

my-neuro 现在有三份给用户看的说明。先看你打开的是哪一个窗口，再点对应入口。

| 你正在用的东西 | 该看哪份 |
| --- | --- |
| 桌面上的 **肥牛.exe**，窗口标题是「My-Neuro (本地)」，左侧栏有启动、模型配置、终端控制室 | **本站（肥牛.exe 教程）** |
| 浏览器「My Neuro - 控制中心」，顶栏是启动、LLM 配置、云端配置 | [WebUI 文档](/) |
| 安装包怎么下、更旧的箭头截图 | [官网教程](http://mynewbot.com/tutorials)（补充，栏目表见 [官网教程（补充）](/qt/guide/official)） |

官网是补充，会继续保留下载和更旧截图。本站从「已经解压好、打开肥牛.exe」写起。官网图里若还写「更新配置」，以你屏幕上的字为准。

::: warning 模型填法不一样
肥牛.exe 的 **模型配置** 是同一页四项：API KEY、API URL、模型名称、系统提示词，模型名称可以点 **获取模型** 直接拉列表。

WebUI 是「多个提供商，每个提供商一份模型列表」，再到功能配置里选出这次用的模型。

两边的保存按钮现在都叫 **保存配置**，但页面结构不同——不要照着一边的截图去另一边找按钮。
:::

::: tip 记忆服务在哪里
旧版教程把记忆服务写在终端控制室里。新版不是了：记忆是 **MemOS 插件**，在「插件」页配置，步骤见 [记忆](/qt/config/memory)。
:::
