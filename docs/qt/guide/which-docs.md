# 三份文档怎么选

my-neuro 现在有三份给用户看的说明。先看你打开的是哪一个窗口，再点对应入口。

| 你正在用的东西 | 该看哪份 |
| --- | --- |
| 桌面上的 **肥牛.exe**，左侧栏是启动、LLM配置、终端控制室 | **本站（肥牛.exe 教程）** |
| 浏览器「My Neuro - 控制中心」，顶栏是启动、LLM 配置、云端配置 | [WebUI 文档](/) |
| 安装包怎么下、更旧的箭头截图 | [官网教程](http://mynewbot.com/tutorials) |

官网会继续保留下载和旧图。本站从「已经解压好、打开肥牛.exe」写起。

::: warning LLM 填法不一样
肥牛.exe 是同一页四个框：API KEY、API URL、模型名称、AI人设，改完点 **更新配置**。

WebUI 是「多个提供商，每个提供商一份模型列表」，再到功能配置里选出这次用的模型，保存按钮写的是 **保存配置**。

不要把网页教程里的按钮名拿到 exe 里找「长得像的」去点。
:::

交流群：肥牛.exe 手册里写的是 **756741478**；WebUI 文档里写的是 **518300858**。两个都保留，不合并。
