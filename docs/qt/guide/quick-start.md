# 快速开始

先确认 `肥牛.exe` 能打开、桌面上能出现角色，再填聊天模型。听和说不要一上来全开。

## 你需要先有的东西

- 已解压的 my-neuro 安装目录（路径不要有中文、空格、括号）
- `live-2d` 里的 **肥牛.exe**
- 一个 OpenAI 兼容的大模型 API（Key、地址、模型名）

只想临时体验、先不装本地语音，可以走 [全云端体验](/qt/config/cloud)。

## 1. 打开肥牛.exe

进入安装目录下的 `live-2d`，双击 **肥牛.exe**。应出现带左侧栏的窗口，标题类似 **My-Neuro (本地)**。

## 2. 先点启动桌宠

左侧栏停在 **启动**。点绿色的 **启动桌宠**。

![启动页上的启动桌宠](/images/qt/qt-start-pet.png)

怎样算成功：桌面上出现角色，一般还带输入框。手册里用红框标出的就是这两处。

![桌面上出现的角色](/images/qt/qt-desktop-running.png)

这一步只证明主程序能起来。还不能稳定聊天时，先关掉桌宠，去做下一步。

## 3. 填 LLM 四件套

左侧栏打开 **LLM配置**，填：

- **API KEY**
- **API URL**
- **模型名称**
- **AI人设**

点底栏 **更新配置**。图上的地址和模型名是示例，填你自己的。

![LLM 四个输入框](/images/qt/qt-llm-four.png)

主模型不能看图时，到 **对话设置** 里配辅助视觉，见 [LLM 四件套](/qt/config/llm)。

## 4. 再启动桌宠，说一句或打一句

回到 **启动**，再点 **启动桌宠**。在输入框打字发送，或等听的一侧配好后再说话。

能看到回复或字幕，这一页就完成了。
