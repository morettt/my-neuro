# 快速开始

先确认 `肥牛.exe` 能打开、桌面上能出现角色，再填聊天模型。听和说不要一上来全开。

## 你需要先有的东西

- 已解压的 my-neuro 安装目录（路径尽量纯英文，不要有空格、括号）
- `live-2d` 里的 **肥牛.exe**
- 一个 OpenAI 兼容的大模型 API（Key、地址、模型名）

只想临时体验、先不装本地语音，可以走 [全云端体验](/qt/config/cloud)。

## 1. 打开肥牛.exe

进入安装目录下的 `live-2d`，双击 **肥牛.exe**。第一次打开会先解压几秒钟，然后出现带左侧栏的窗口，标题类似 **My-Neuro (本地)**。

## 2. 先点启动桌宠

左侧栏停在 **启动**。点右侧的 **▶ 启动桌宠**（红框标出的就是它）。

![启动页上的启动桌宠](/images/qt/qt-start-pet.png)

怎样算成功：桌面上出现角色。再点一次同一位置，按钮会变成 **■ 关闭桌宠**，说明桌宠正在运行。

这一步只证明主程序能起来。还不能稳定聊天时，先点 **■ 关闭桌宠**，去做下一步。

## 3. 填模型配置

左侧栏打开 **模型配置**，填四项：

- **API KEY**
- **API URL**
- **模型名称** — 填好 Key 和地址后，也可以直接点 **获取模型** 让它拉列表选一个
- **系统提示词** — 角色怎么说话、你怎么称呼对方

填完点底部的 **保存配置**。图上的 Key、地址是空的，填你自己在提供商控制台拿到的值。

![模型配置的四个输入项](/images/qt/qt-model-config.png)

## 4. 重启桌宠，说一句

回到 **启动**，先 **■ 关闭桌宠**，再 **▶ 启动桌宠**——新保存的配置要重启桌宠才生效。

桌面上出现角色后，在角色旁的 **文字输入框** 里打一句发出去（看不到输入框时，到 **对话设置** 打开「文字输入框」再重启桌宠）。稍等片刻，角色的字幕里出现回复，这一页就完成了。第一次对话可能比较慢，只要后来出了字，就算成功。
