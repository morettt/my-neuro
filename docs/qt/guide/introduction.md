# 介绍

这份教程讲的是桌面上的 **`肥牛.exe`**：窗口标题类似 **My-Neuro (本地)**，左边一列按钮换页，底栏保存叫 **更新配置**。

要用浏览器里的「My Neuro - 控制中心」，请去 [WebUI 文档](/)。两边按钮不是同一套。

::: tip
想先确认窗口能开、角色能出来，直接看 [快速开始](./quick-start.md)。
:::

## 你下载了什么

my-neuro（社区常叫「肥牛」）不是单纯的网页聊天框。它是一个桌面 AI 桌宠工作台：角色以 Live2D 等形式待在桌面上，可以聊天、说话、记事情，再通过插件去查资料、写文件、看直播等。

可以把它理解成：

- 会说话的桌宠
- 会记忆的 AI 伙伴
- 能调用很多插件的小助手

使用上，核心是 **`肥牛.exe`（或另一套 WebUI）+ 插件** 一起工作。本站只写 exe 这一套怎么点。

安装目录里也能看到网页入口。要打开的是 **肥牛.exe**，不是 `启动 WebUI 控制面板.bat`。

![目录里框出的肥牛.exe 与 WebUI 启动脚本](/images/qt/qt-open-exe-vs-webui.png)

## 几个名词

**肥牛.exe** 是桌宠本体所在的窗口：语音、字幕、模型、截图、聊天框，都从这里管。

**插件** 负责具体能力，类似给手机装 App：记忆、写文件、开软件、查天气、弹幕等。

![插件像附加能力](/images/qt/qt-noun-plugin.png)

**启用列表** 决定哪些插件真的生效。目录里有插件文件夹，不等于已经打开。

![启用列表](/images/qt/qt-noun-enable.png)

**配置**（`config.json`）里是 API、路径、模型、是否主动说话等。日常在窗口里改、点 **更新配置** 即可，不必先去翻文件。

![配置文件的位置概念](/images/qt/qt-noun-config.png)

**API KEY** 是调用模型的钥匙。**API URL** 是接口地址。**模型名称** 按提供商规范填：硅基流动一类常见是 `品牌/型号`，有的官方接口只填型号。

**UI** 就是打开肥牛.exe 后看到的这个桌面窗口。WebUI 是网页版的同一类工作台，操作路径不同，见 [三份文档怎么选](./which-docs.md)。

本站沿用两个叫法：**皮套** 指角色形象（Live2D 等）；**桌宠** 指点了 **启动桌宠** 之后出现在桌面上的角色。
