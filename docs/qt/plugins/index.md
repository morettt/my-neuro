# 在肥牛.exe 里用插件

插件是附加能力。目录里有文件夹，不等于已经打开。要在左侧栏 **插件** 里启用，需要配置的再点配置，最后 **更新配置**。

![启用列表决定哪些插件生效](/images/qt/qt-noun-enable.png)

插件像给本体加 App。记忆、写文件、弹幕、翻译，都走这一页。

![插件是附加能力](/images/qt/qt-noun-plugin.png)

## 这页只写 exe 里怎么开

每个插件干什么、默认间隔是多少秒，已经写在 WebUI 文档里，这里不抄第二遍。顶栏切到 **WebUI**，打开：

- [使用插件](/plugins/)
- [内置插件](/plugins/built-in)
- [社区插件](/plugins/community)

若链接仍停在肥牛.exe 站点里，用顶栏的 **WebUI** 切换后再点侧栏「插件」。

## 手册里点过名的两个

**上下文压缩**：历史被条数截断后，用它把旧对话收成要点，减轻「突然忘了上一轮」。

![上下文压缩插件](/images/qt/qt-compressor-plugin.png)

**同声传译**：TTS 用外语、字幕保持中文时用。还要给翻译填模型、URL、Key。TTS 语言见 [怎么说](/qt/config/speak)。

![同声传译插件](/images/qt/qt-translation-plugin.png)

MemOS 长期记忆的启动步骤在 [记忆](/qt/config/memory)。
