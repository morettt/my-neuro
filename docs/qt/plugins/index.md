# 在肥牛.exe 里用插件

插件是附加能力。目录里有文件夹，不等于已经打开。要在左侧栏 **插件** 页启用，需要配置的再点配置，最后 **保存配置** 并重启桌宠。

## 插件页长什么样

顶部三个标签：**内置插件 / 社区插件 / 插件广场**。

![内置插件列表](/images/qt/qt-plugins-builtin.png)

- **内置插件** — 随主程序一起装的官方插件
- **社区插件** — 你自己（或从广场）装进 `plugins/community` 的插件
- **插件广场** — 在线列表，点 **安装** 直接装，**仓库** 跳到源码仓库；列表变了点右上角 **刷新列表**

![插件广场](/images/qt/qt-plugins-market.png)

每张卡片上：**启用** 开关决定生不生效；**配置** 打开这个插件自己的设置；有的插件需要额外的本地组件，卡片上会出现 **安装 DLC** 按钮，装完才变成开关；还有少数插件自带服务，卡片上有 **启动** 按钮。

点卡片本体可以进详情页，左上角 **← 返回插件列表** 回来，右上角 **使用教程** 打开这个插件自己的说明——每个插件干什么、每个配置项是什么意思，以那份教程为准，这里不抄第二遍。

每个插件的具体能力清单（含默认间隔多少秒）也已写在 WebUI 文档里，顶栏切到 **WebUI** 再打开：

- [使用插件](/plugins/)
- [内置插件](/plugins/built-in)
- [社区插件](/plugins/community)

## 手册里点过名的几个

**上下文压缩**：历史被条数截断后，用它把旧对话收成要点，减轻「突然忘了上一轮」。配合 [对话设置的上下文限制](/qt/config/ui) 使用。

**同声传译**：TTS 用外语、字幕保持中文时用。还要给翻译填模型、URL、Key。TTS 语言见 [怎么说](/qt/config/speak)。

**MemOS 长期记忆**：跨天记忆的本体，启动步骤单独写在 [记忆](/qt/config/memory)。
