# 怎么听

电脑的麦克风只会录音。要把你说的话变成字，需要 **ASR**（语音识别）。过程是：声音 → ASR 识别 → 屏幕上的文字。

## 1. 在终端控制室启动 ASR

左侧栏 **终端控制室**，切到 **ASR** 标签，点 **启动**（红框标出）。

![终端控制室的 ASR 标签](/images/qt/qt-terminal-asr.png)

新版服务在后台运行，不会再弹黑色终端窗口。看这一页两处就算成功：

- 状态一行从 **未启动 · 端口 1000** 变成运行中
- 下方的 **ASR 日志** 开始滚动输出加载信息

模型还没装时，「启动」的位置会变成 **下载 ASR** 按钮，点它先下载模块（体积较大，耐心等），完成后再启动。

## 2. 重启桌宠，说一句话

回 **启动** 页把桌宠关掉再启动，然后对着麦克风说一句。识别出来的字会出现在桌面的字幕或聊天框里。第一次可能有一点延迟。

## 怎样算失败

说话没有任何字出现：先回 ASR 标签看状态是不是又变回「未启动」、日志里有没有报错，把报错拿去 [常见问题](/qt/faq) 对照。

## 不用本地麦克风

打开 **云端配置**，切到 **云端 ASR** 标签，选好平台、填 Key、打开「启用云端 ASR」。云端和本地 ASR 只开一个。

![云端 ASR 配置](/images/qt/qt-cloud-asr.png)
