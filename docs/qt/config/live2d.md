# 皮套与动作

## 换皮套

把 Live2D 模型文件放到安装目录的 `live-2d/2D` 文件夹（VRM 模型同理放进对应目录）。

打开肥牛.exe，在 **启动** 页点 **当前桌宠** 下拉框，列表里会出现你的模型，点一个切换，然后重启桌宠。

![当前桌宠下拉选择](/images/qt/qt-live2d-select.png)

## 表情与动作

左侧栏 **表情与动作**，这一页有四个标签：**唱歌控制 / VMC / 表情控制 / 动作控制**。日常只动后两个。

**动作控制**：把下方「未分类动作」里的动作卡拖到上面的情绪分类（开心、生气、难过、惊讶、害羞、俏皮）；不确定哪个是哪个，先点一下动作卡预览。分配错了点右上角 **一键还原动作** 重来。

![动作控制：拖拽分配](/images/qt/qt-motion.png)

**表情控制**：玩法一样，把表情拖到情绪区域，点 **一键还原表情** 复位。

![表情控制：拖拽分配](/images/qt/qt-expression.png)

**唱歌控制 / VMC** 是进阶功能（点歌、动作数据转发），新手可以不碰。

改完点 **保存配置**，重启桌宠生效。之后对话里出现 `<开心>` 这类情绪标签时，角色就会做对应的动作和表情。

## 皮套飞出屏幕

角色不是消失了，多半跑到屏幕外面。到 **对话设置** 点 **复位皮套位置** 把它拉回来，见 [界面与打断](/qt/config/ui)。
