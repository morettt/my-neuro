# 皮套与动作

## 换皮套

把 Live2D 模型文件放到安装目录的 `live-2d/2D` 文件夹。

![皮套放到 2D 文件夹](/images/qt/qt-live2d-folder.png)

打开肥牛.exe，在 **启动** 页的 **Live2D模型选择** 里换成你的模型。

![Live2D模型选择](/images/qt/qt-live2d-select.png)

## 没有表情、一直一个姿势

到 **表情与动作**，把动作和表情拖到对应槽位。不确定哪个是哪个，先点预览再拖。

![拖拽表情与动作](/images/qt/qt-emotion-drag-1.png)

![继续配置动作槽位](/images/qt/qt-emotion-drag-2.png)

## 皮套飞出屏幕

角色不是消失了，多半跑到屏幕外面。用复原位置把它拉回来。

![复原皮套位置](/images/qt/qt-reset-position.png)
