# LLM 四件套

左侧栏 **LLM配置**。这一页四个框填完，桌宠才有「脑子」。图上的 Key、地址、模型名是示例，填你自己在提供商控制台拿到的值。

![API KEY、API URL、模型名称、AI人设](/images/qt/qt-llm-four.png)

| 界面标题 | 填什么 |
| --- | --- |
| API KEY | 调用模型的钥匙 |
| API URL | 接口地址，一般要带提供商要求的路径（常见会有 `/v1`） |
| 模型名称 | 控制台里的模型 ID。硅基流动一类常写成 `品牌/型号`；有的官方接口只填型号 |
| AI人设 | 角色怎么说话、你怎么称呼对方 |

填完点 **更新配置**。再回到 **启动** 点 **启动桌宠**。

推荐用 OpenAI 兼容接口。WebUI 文档里写的 [RabbitAPI](https://rabbitapi.online/)（需要梯子）同样能用，但 **填法仍是这四个框**，不要去 exe 里找「添加提供商」。

## 这个模型能看图吗

主模型能看图，后面测截图、看屏幕会省事。不能看图时：打开 **对话设置**，找到辅助视觉，填一个能看图的模型的 Key / 地址 / 名称，并打开开关。

不要填只会做 OCR、不能当视觉模型用的接口。

![对话设置里的辅助视觉](/images/qt/qt-vision-assist.png)

拿不准就查提供商说明，或到群 **756741478** 问一声。

## 温度

角色太死板或太乱，到对应控件改 **温度**。具体数值问群友往往比猜更快。截图见 [界面与打断](/qt/config/ui)。
