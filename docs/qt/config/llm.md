# 模型配置

左侧栏 **模型配置**。这一页四项填完，桌宠才有「脑子」。图上的 Key、地址是空的，填你自己在提供商控制台拿到的值。

![API KEY、API URL、模型名称、系统提示词](/images/qt/qt-model-config.png)

| 界面项 | 填什么 |
| --- | --- |
| API KEY | 调用模型的钥匙，输入框右边的眼睛可以显示/隐藏明文 |
| API URL | 接口地址，一般要带提供商要求的路径（常见会有 `/v1`） |
| 模型名称 | 控制台里的模型 ID。硅基流动一类常写成 `品牌/型号`；有的官方接口只填型号 |
| 系统提示词 | 角色怎么说话、你怎么称呼对方 |

## 获取模型

不想手打模型名：填好 **API KEY** 和 **API URL** 后，点模型名称旁边的 **获取模型**，它会从你的提供商那里拉回可用模型列表，点一个即可。

拉取失败多半是 Key 或地址没填对，先回去检查这两项。

填完点底部 **保存配置**，再回到 **启动** 把桌宠关掉重启一次。推荐用 OpenAI 兼容接口。WebUI 文档里写的 [RabbitAPI](https://rabbitapi.online/)（需要梯子）同样能用，但 **填法仍是这一页四项**，不要去 exe 里找「添加提供商」。

## 这个模型能看图吗

主模型能看图，后面测截图、看屏幕会省事。不能看图时：打开 **对话设置**，切到 **辅助视觉** 标签，打开「启用辅助视觉模型」，填一个能看图的模型的 Key / 地址 / 名称。

不要填只会做 OCR、不能当视觉模型用的接口。

![对话设置的辅助视觉标签](/images/qt/qt-vision-assist.png)

拿不准就查提供商说明，或到群 **756741478** 问一声。

## 温度

角色太死板或太乱，到 **对话设置** 打开「启用温度」，点旁边的 **配置** 调数值。具体数值问群友往往比猜更快，见 [界面与打断](/qt/config/ui)。
