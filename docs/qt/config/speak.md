# 怎么说

大多数聊天模型只出文字。要让桌宠开口，需要 **TTS**（给角色用的发音，不是你的麦克风）。

## 1. 在终端控制室启动 TTS

左侧栏 **终端控制室**，切到 **TTS** 标签，点 **启动**（红框标出）。

![终端控制室的 TTS 标签](/images/qt/qt-terminal-tts.png)

和 ASR 一样，服务在后台运行。状态一行从 **未启动 · 端口 5000** 变成运行中，下方 **TTS 日志** 开始滚动，就算起来了。模型没装时按钮会变成 **下载 TTS**，先下载再启动。

## 2. 启动桌宠，听一声

回 **启动**，把桌宠重启一次。等角色打完招呼，对它说一句或打一句。能听到声音，这一项就过了。第一次合成可能较慢。

## 换声音、改用语种

- **换音色**（已有本地 TTS 模型）：按 [官网教程](http://mynewbot.com/tutorials)
- **没有本地 TTS 模型**：到 **云端配置** 的 **云端 TTS** 标签，平台下拉里有 **阿里云 TTS / 字节 TTS / SiliconFlow TTS**，选一个填 Key 启用。字节 TTS 的面板里还带一个「配置教程」按钮
- **嘴里要外语、字幕要中文**：先在 **对话设置** 里把 **语音语言** 换成 English / 日本語，再启用同声传译插件并给翻译填一套模型 / URL / Key，见 [在肥牛.exe 里用插件](/qt/plugins/)

![云端 TTS：平台选择](/images/qt/qt-cloud-tts.png)

## 声音克隆

TTS 标签里有一个 **声音克隆** 按钮，点进去就是克隆页：上传模型文件（.pth）和参考音频（.wav），填角色名称和参考文本，生成脚本后用克隆出来的音色。没有本地 TTS 时这一项用不了。
