# 截图（BERT）

BERT 用来判断对话时要不要「睁眼」看屏幕，也就是要不要主动截图。不是让你在终端里做题。

## 启动

左侧栏 **终端控制室** → **BERT** 标签 → 点 **启动**（红框标出）。

![终端控制室的 BERT 标签](/images/qt/qt-terminal-bert.png)

状态一行从 **未启动 · 端口 6007** 变成运行中，下方 **BERT 日志** 开始滚动，这一项就成功了。模型没装时按钮会变成 **下载 BERT**，先下载再启动。

## 看不看桌面

- **启动页的「每次对话识图」**：打开后每次对话都截一张屏幕给 AI 看，响应会变慢，按需开关
- 启动页还有 **开启 MCP**、**开启语音打断** 两个开关，别和识图搞混

![启动页的识图与打断开关](/images/qt/qt-start-pet.png)

主模型不能看图时，先去 **对话设置 → 辅助视觉** 配一个视觉模型，见 [模型配置](/qt/config/llm#这个模型能看图吗)。
