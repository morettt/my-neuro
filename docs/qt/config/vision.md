# 截图（BERT）

BERT 用来判断对话时要不要「睁眼」看屏幕，也就是要不要主动截图。不是让你在终端里做题。

## 启动

左侧栏 **终端控制室** → **启动 BERT**。

![终端控制室启动 BERT](/images/qt/qt-bert-start.png)

等到黑窗口出现图上那一行，这一项就成功了。手册里这一步不用再对着桌宠测一遍。

![BERT 终端就绪](/images/qt/qt-bert-ready.png)

黑窗口不要关。

## 看不看桌面

不想让它看见桌面、或反过来一定要看见，在对应开关上改：

![看桌面相关开关](/images/qt/qt-see-desktop.png)

主模型不能看图时，先配 [辅助视觉](/qt/config/llm#这个模型能看图吗)。
