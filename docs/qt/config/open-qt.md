# 认识肥牛.exe

双击 `live-2d/肥牛.exe` 后，应看到左侧一列按钮、右侧一大块内容、底栏 **更新配置**。窗口标题类似 **My-Neuro (本地) v6.5.1**。

## 左侧栏

按截图从上到下：

1. **启动** — 启动桌宠、日志、Live2D 模型选择、语音打断等
2. **LLM配置** — 四个框填模型
3. **插件** — 启用、配置插件
4. **对话设置** — ASR 总开关、辅助视觉、历史条数等
5. **工具屋** — 广场类入口
6. **UI设置** — 字幕、隐藏皮套、关窗口时停服务
7. **表情与动作** — 把动作拖到槽位
8. **声音克隆** — 有本地 TTS 时才会用到
9. **终端控制室** — 启动 ASR / TTS / BERT / 记忆等黑窗口
10. **云端配置** — 云端肥牛、云端 TTS、阿里云 TTS、字节 TTS、百度流式 ASR

点哪一栏，右侧就换哪一页。改完点 **更新配置**，不要找 WebUI 上的「保存配置」。

配置实际写在安装目录的 `config.json` 里。日常在窗口里改即可，不必先去翻这个文件。

![配置文件的位置](/images/qt/qt-noun-config.png)

## 启动页上常见按钮

- **启动桌宠** — 让角色出现在桌面上
- **清空日志**
- Live2D 模型下拉
- 勾选：MCP、每次对话识图、**开启语音打断**

![启动页：启动桌宠](/images/qt/qt-start-pet.png)

第一次用：先点启动桌宠，确认桌面上有角色，再去填 LLM。完整顺序见 [快速开始](/qt/guide/quick-start)。
