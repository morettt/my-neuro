# 认识肥牛.exe

双击 `live-2d/肥牛.exe`，先解压几秒，然后应看到：左边一列按钮、右边一大块内容、底部一条 **保存配置**。窗口标题类似 **My-Neuro (本地) v6.7**。

![启动页：启动桌宠与日志](/images/qt/qt-start-pet.png)

## 标题栏

右上角除了最小化、最大化、关闭，还有三个小图标：

- **📖 使用教程** — 打开窗口里自带的一份简短教程，忘了步骤时先点它
- **🐧 QQ群** — 弹出二维码，扫码进群

![QQ群二维码弹窗](/images/qt/qt-qq-group.png)

- **GitHub** — 打开项目仓库

## 左侧栏

按截图从上到下：

1. **启动** — 启动桌宠、Live2D 模型选择、语音打断、MCP、识图开关和日志
2. **模型配置** — API KEY、API URL、模型名称、系统提示词
3. **提示词广场** — 一键应用别人调好的人设提示词
4. **插件** — 启用、配置插件，社区插件和插件广场也在这一页
5. **对话记录** — 回看和桌宠的历史对话
6. **对话设置** — 语音语言、输入方式、上下文限制、温度、辅助视觉
7. **表情与动作** — 把动作和表情拖到情绪槽位
8. **终端控制室** — 启动 TTS / ASR / BERT 三个本地服务
9. **工具屋** — MCP 工具管理和工具广场
10. **云端配置** — 云端肥牛、云端 TTS、云端 ASR
11. **UI设置** — 字幕、隐藏皮套、显示名称、开场白

点哪一栏，右边就换哪一页。改完点底部 **保存配置**。改完想让桌宠用上新配置，把它关掉再启动一次。

配置实际写在安装目录的 `live-2d/config.json` 里。日常在窗口里改即可，不必先去翻这个文件。

## 启动页上有什么

- **当前桌宠** — 下拉选择 Live2D 或 VRM 模型
- **▶ 启动桌宠 / ■ 关闭桌宠** — 同一个按钮：没启动时显示启动，运行中显示关闭
- **开启 MCP** — 让桌宠接上 MCP 外部工具，新手先不用开
- **每次对话识图** — 每句话都让 AI 看一眼屏幕，会增加延迟
- **开启语音打断** — 她说话时你可以直接出声打断
- **桌宠日志 / 工具日志** — 运行情况实时显示在这里，出问题先看这两个；右上角垃圾桶图标是清空日志

第一次用：先点启动桌宠，确认桌面上有角色，再去填模型。完整顺序见 [快速开始](/qt/guide/quick-start)。
