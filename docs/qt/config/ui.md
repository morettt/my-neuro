# 界面与打断

这些开关都在肥牛.exe 里，改完点底部 **保存配置**，再重启桌宠生效。

## 对话设置

左侧栏 **对话设置** 的 **基础设置** 标签：

![对话设置：基础设置](/images/qt/qt-chat-settings.png)

- **语音语言** — 中文 / English / 日本語，决定 TTS 嘴里的语种
- **文字输入框（可打字交互）** — 打开后桌宠旁边有输入框，可以打字聊天
- **键盘语音输入（按住V键录音）** — 按住 V 说话，替代点麦克风按钮
- **启用上下文限制** — 打开后点旁边 **配置**，限制每次带给模型的历史条数，觉得花钱太快就开这个
- **启用对话历史记忆** — 让对话上下文跨启动保留。如果出现复读、混乱，先把它关掉
- **启用温度** — 打开后点旁边 **配置** 调数值。角色太死板或太跳就动它，具体数字可以问群 **756741478**
- **复位皮套位置** — 角色飞出屏幕外时点它拉回来
- **调整字幕位置** — 字幕拖丢了、位置不对时点它

截断之后仍想留住上一轮要点，开上下文压缩插件，见 [在肥牛.exe 里用插件](/qt/plugins/)。

## 启动页的打断

角色说个不停时，到 **启动** 页打开 **开启语音打断**，就可以在她说话时直接出声打断。

## UI设置

左侧栏 **UI设置**：

![UI设置](/images/qt/qt-ui-settings.png)

- **当前版本** — 显示本地版本 / 云端版本和版本号，报问题时先看这一行
- **开场白** — 每次启动桌宠时她说的第一句话
- **用户显示名称 / AI显示名称** — 聊天记录里区分你和 AI 的名字
- **启用字幕显示** — 关掉后角色说话不显示字幕条
- **隐藏皮套** — 程序继续跑，桌面上不显示角色
- **预览本地样式 / 切回云端样式** — 切换界面预览。不小心切到云端样式后，本地版会看不到终端控制室等入口，再点一次切回来就好

## 对话记录

左侧栏 **对话记录** 可以回看历史对话，底下分页翻。诊断「它刚才说了什么」时很有用。
