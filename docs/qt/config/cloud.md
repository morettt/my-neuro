# 全云端体验

只想**临时试试**桌宠、还不打算把本地 ASR / TTS 全部装齐时，用云端肥牛。听、说、对话都在云端跑，电脑上不必先起那几个黑窗口。

想长期留下、用本地麦克风和本地声音，走 [快速开始](/qt/guide/quick-start)，再测 [怎么听](/qt/config/listen) 和 [怎么说](/qt/config/speak)。

## 步骤

1. 左侧栏 **云端配置**
2. 子页 **云端肥牛**
3. 按页面提示申请密钥（图上绿色按钮会打开官网）
4. 把密钥填进 **肥牛密钥**
5. 勾上 **启动全云端**
6. 点 **更新配置**
7. 回到 **启动**，点 **启动桌宠**

![云端肥牛：申请密钥与启动全云端](/images/qt/qt-cloud-full.png)

图上的 URL 是示例。密钥用你自己申请的，不要借用别人的。

## 只把听或说放到云端

不一定要「全云端」。也可以只在 **云端配置** 里打开某一种云端 TTS 或云端 ASR，填法见 [官网教程](http://mynewbot.com/tutorials)。
