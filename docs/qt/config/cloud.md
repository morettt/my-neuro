# 全云端体验

只想**临时试试**桌宠、还不打算把本地 ASR / TTS 全部装齐时，用云端肥牛。听、说、对话都在云端跑，电脑上不必先起本地服务。

想长期留下、用本地麦克风和本地声音，走 [快速开始](/qt/guide/quick-start)，再测 [怎么听](/qt/config/listen) 和 [怎么说](/qt/config/speak)。

## 步骤

1. 左侧栏 **云端配置**
2. 停在 **云端肥牛** 标签
3. 点 **🔗 获取 API KEY - 前往云端肥牛官网**，按页面提示申请密钥
4. 把密钥填进 **肥牛密钥**（右边眼睛可切换明文）
5. 打开 **启动全云端** 开关（红框标出）
6. 点底部 **保存配置**
7. 回到 **启动**，重启桌宠

![云端肥牛：密钥与启动全云端](/images/qt/qt-cloud-gateway.png)

密钥用你自己申请的，不要借用别人的。

## 只把听或说放到云端

不一定要「全云端」。云端配置还有两个标签，可以单独只开说或只开听：

- **云端 TTS** — 平台下拉里选 **阿里云 TTS / 字节 TTS / SiliconFlow TTS**，按平台填 Key 和音色，打开「启用云端 TTS」。字节 TTS 面板里带「配置教程」按钮
- **云端 ASR** — 平台选 **SiliconFlow ASR**，填 Key、挑一个模型，打开「启用云端 ASR」

![云端 TTS 平台选择](/images/qt/qt-cloud-tts.png)

![云端 ASR 平台选择](/images/qt/qt-cloud-asr.png)

同一类听或说，云端和本地只开一个，免得两边抢麦克风、抢音箱。开了云端方案后，本地对应的 TTS / ASR 服务就不用在终端控制室启动了。
