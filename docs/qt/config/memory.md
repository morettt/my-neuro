# 记忆

长期记忆让角色还记得你们昨天说过的话。新版里记忆是 **MemOS 插件**：先在插件页配置，再把记忆后端跑起来。

::: warning 老用户注意
旧版教程写的「终端控制室最后一行启动记忆」已经没有了——终端控制室现在只有 TTS / ASR / BERT 三个标签。记忆按本页的插件流程走。
:::

更细的配置项含义也可以在插件详情页右上角点 **使用教程** 看。

## 1. 打开 MemOS 配置

左侧栏 **插件** → 内置插件列表里找到 **MemOS 长期记忆** → 点 **配置**。

![插件列表里的 MemOS 长期记忆](/images/qt/qt-memos-plugin.png)

## 2. 填基本项

打开 **启用 MemOS**（红框标出）。**MemOS API 地址** 保持默认的 `http://127.0.0.1:8003` 不动。

下面几项保持默认就能用：自动注入记忆、注入记忆条数、相似度阈值、自动保存对话、保存间隔（轮）。想调再调，鼠标放到各项下面的灰色小字上有说明。

![MemOS 配置详情页](/images/qt/qt-memos-config.png)

## 3. 给记忆填一个 LLM

往下滚到 **后端 LLM 配置**。这是给记忆后端用来总结对话、提取实体的模型，不是聊天模型：

- **模型名称**
- **API Key**
- **Base URL**

可以和聊天模型用同一家。填完点底部 **保存配置**。

![后端 LLM 配置](/images/qt/qt-memos-llm.png)

## 4. 启动记忆后端

到安装目录的 `plugins-dlc/memos` 里，运行 **MEMOS-API.bat**，等它把服务拉起来（默认端口就是上面的 8003）。整合包没带这个文件夹时，先在 **插件 → 插件广场** 里安装 MemOS，装完同一路径就有了。

## 5. 验证

回 **启动** 重启桌宠，聊几句。第二天再提昨天聊过的事它还能接上，记忆就在工作了。想核对，去 **对话记录** 页翻历史。
