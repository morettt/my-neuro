# 常见问题

按现象找。按钮对不上时，先确认你打开的是 **肥牛.exe**，不是浏览器控制中心。分流见 [三份文档怎么选](/qt/guide/which-docs)。

## 模型报了一堆英文

先看启动页日志，或 ASR / TTS 那个黑窗口。不必每一词都懂，先圈出能读的英文。

例如日志里出现 `Invalid API Key or monthly quota exceeded`，或中文「API访问被禁止」「额度已用完」，意思是 Key 不对，或额度用完了。换一把有效的钥匙，或去提供商处确认余额。

![日志里的 Invalid API Key](/images/qt/qt-error-api-key.png)

看不懂就把整段日志复制给别的 AI 问。还是不行，到群 **756741478**。

## 第一次对话很慢

正常。只要后来出了字或声音，功能就算起来了。

## 我关掉了黑色小窗口，语音没了

ASR、TTS、BERT、记忆都靠这些终端窗口。不要关；可以最小化。只有确定不用这项功能时再停。

## 桌面上没有角色

先在 **启动** 页点 **启动桌宠**。已经点过却看不见，可能飞出屏幕，见 [皮套与动作](/qt/config/live2d)。

## 能出字听不到声 / 能听见但不识别我说话

听和说是两套。分别按 [怎么听](/qt/config/listen)、[怎么说](/qt/config/speak) 检查终端是否就绪、对话设置里 ASR 是否勾上。

临时不想装本地模型，见 [全云端体验](/qt/config/cloud)。
