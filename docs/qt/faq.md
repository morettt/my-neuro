# 常见问题

按现象找。按钮对不上时，先确认你打开的是 **肥牛.exe**（窗口标题 My-Neuro (本地)），不是浏览器控制中心。分流见 [三份文档怎么选](/qt/guide/which-docs)。安装包和更旧截图看 [官网教程](http://mynewbot.com/tutorials)，栏目表在 [官网教程（补充）](/qt/guide/official)。

## 日志去哪看了

新版不需要盯黑窗口：

- 启动页有 **桌宠日志** 和 **工具日志** 两块，主程序和插件的输出都在这里
- 终端控制室每个服务标签（TTS / ASR / BERT）下方各有一块日志，服务出问题先看对应的

## 模型报了一堆英文

先看启动页 **桌宠日志**，或终端控制室里对应服务的日志。不必每个词都懂，先圈出能读的英文。

例如日志里出现 `Invalid API Key or monthly quota exceeded`，或中文「API访问被禁止」「额度已用完」，意思是 Key 不对，或额度用完了。换一把有效的钥匙，或去提供商处确认余额，改完 **保存配置** 并重启桌宠。

看不懂就把整段日志复制给别的 AI 问。还是不行，到群 **756741478**（标题栏的 **QQ群** 图标可以扫码进）。

## 第一次对话很慢

正常。只要后来出了字或声音，功能就算起来了。

## 改了配置没生效

检查两点：底部 **保存配置** 点了没有；**启动** 页把桌宠关掉重启了没有。新版配置要重启桌宠才会被角色用上。

## 服务停了 / 语音没了

终端控制室对应标签里看状态：显示 **未启动** 就再点一次 **启动**。模型被删过的话，按钮会变成 **下载 TTS / ASR / BERT**，先下载完再启动。

## 桌面上没有角色

先在 **启动** 页点 **▶ 启动桌宠**。已经点过却看不见，可能飞出屏幕，到 **对话设置** 点 **复位皮套位置**，见 [皮套与动作](/qt/config/live2d)。

## 能出字听不到声 / 能听见但不识别我说话

听和说是两套。分别到终端控制室的 **TTS**、**ASR** 标签确认状态是运行中；TTS 没声音再查对话设置的 **语音语言** 和音色配置。

临时不想装本地模型，见 [全云端体验](/qt/config/cloud)。

## 界面少了几栏 / 样式不对

到 **UI设置** 点一下 **预览本地样式 / 切回云端样式**——这个按钮会切换界面预览，切回本地样式后侧边栏就全了。
