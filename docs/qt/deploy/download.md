# 下载与打开

安装包怎么选、怎么解压，以 [官网教程](http://mynewbot.com/tutorials) 为准。本页只补打开肥牛.exe 之前要注意的几件事。

## 路径

整个安装目录不要带中文、空格、括号。出错时先把文件夹挪到纯英文路径再开 exe。

## 打开哪一个

在 `live-2d` 里双击 **肥牛.exe**。

不要用 `启动 WebUI 控制面板.bat` 来跟这份教程对按钮——那是网页控制中心，请看 [WebUI 文档](/)。

![肥牛.exe 与 WebUI 启动脚本](/images/qt/qt-open-exe-vs-webui.png)

更新发行包的方式见官网或 [WebUI 文档的更新页](/deploy/update)。更新前备份 `live-2d/config.json` 以及你改过的人设、插件配置。

接下来：[认识肥牛.exe](/qt/config/open-qt)。
