# 常见问题

按现象查找。部署相关注意也写在 [安装](/deploy/install) 和 [更新](/deploy/update)。

## 我该看本站还是官网？

浏览器控制中心 → 本站。`肥牛.exe` / 官网旧截图 → [官网旧教程](http://mynewbot.com/tutorials)。对照 [本站与官网旧教程](/guide/which-docs)。

## 「启动」页看起来像云端，是不是不能用本地麦克风？

不是。没有本地 TTS 模型时，新版会藏起 ASR/TTS 等卡片。听和说分开选：可以用百度流式 ASR，或换一份装了 ASR 的包。

## 找不到 TTS 启动、没有声音克隆？

当前 `full-hub/tts-hub` 没有模型目录。「启动」页只剩 Live2D。去云端配置选一种 TTS。

## 一键启动失败，还能聊天吗？

可以。一键启动会尝试拉很多本地服务。云端 TTS + 打字时，只启动 Live2D 通常就够。本地听则至少把 ASR 启绿。

## 等不到 Live2D 按钮？

你启动过 ASR/TTS/记忆，但端口没起来。看日志，或等约 90 秒超时后手动启动。没点过那些服务则不应被门控拦住。

## 配了本地 TTS 却在走云厂商？

字节 TTS 优先于阿里云，再优先于「云端 TTS」，最后才是本地。关掉你不用的勾选。

## 「启动全云端」要不要开？

界面还在。能连上肥牛网关就按界面填；连不上就关掉，改用阿里云/字节/本地。不要把它理解成「必须开才能聊天」。也不要同时开多种 TTS。

## LLM 报 401 / 模型不存在

Key 错误、URL 少了 `/v1`、或模型名和提供商控制台不一致。在 LLM 配置用「从 API 获取」核对。

## 没有声音

启用 TTS；确认只开一种引擎；本地方案要 5000 端口；云端方案要 Key 和网络。

## 听不见我说话

启用 ASR；本地方案要 1000 端口和麦克风权限；或改用百度流式 ASR。

## 路径有中文导致一堆报错

把整个安装目录挪到纯英文路径后重开 WebUI 和各 bat。

## 显存不足装不了？

安装器在可用显存低于约 5 GB 时会拦住。不勾 TTS，改用云端声音。

## 更新 bat 闪退

可能没有 conda 环境 `my-neuro`。改用发行包自己的更新方式，或备份配置后换新压缩包。

## 功能配置里的「对话历史记忆」

界面上有警告：当前版本可能导致 AI 复读混乱，新手不要勾。
