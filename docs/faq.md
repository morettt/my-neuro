# 常见问题

按现象查找。部署相关的注意事项也写在 [安装](/deploy/install) 和 [更新](/deploy/update)。

## 我该看本站还是官网？

浏览器控制中心看本站；`肥牛.exe` 和官网旧截图看 [官网旧教程](http://mynewbot.com/tutorials)。对照 [本站与官网旧教程](/guide/which-docs)。

## 启动页只有一张卡，是不是不能用麦克风？

不一定。启动页上的服务卡片是否显示，取决于有没有装本地语音模型，见 [介绍](/guide/introduction)。听和说分开选：可以用百度流式 ASR，或换一份装了 ASR 的安装包。

## 找不到 TTS 启动、也没有声音克隆？

这份安装的 `full-hub/tts-hub` 里没有模型目录，所以本地发音相关的入口都不显示。到云端配置选一种 TTS 即可，见 [怎么说](/config/speak)。

## 一键启动失败，还能聊天吗？

能。一键启动会尝试拉起全部本地服务。用云端发音 + 打字时，只启动 Live2D 通常就够；用本地识别时，至少要把 ASR 启到绿灯。

## Live2D 的启动按钮点不动？

你启动过 ASR / TTS / 记忆系统，但端口还没起来。看日志，或等约 90 秒超时后再点。没启动过那些服务时不会被拦住。

## 配了本地 TTS 却在走云厂商？

优先级是字节 TTS → 阿里云 TTS → 云端 TTS → 本地。把你不用的那几个勾选关掉。

## 「启动全云端」要不要开？

它把部分语音请求指到肥牛网关，需要官网发放的地址和 Key。能连上就按 [怎么说](/config/speak) 里方案 E 填；连不上就关掉，改用阿里云 / 字节 / 本地。它不是聊天的前提，也不能和其他 TTS 同时开。

## LLM 报 401 或模型不存在

Key 错误、URL 少了 `/v1`、或模型名和提供商控制台不一致。在 LLM 配置里用「从 API 获取」核对一遍。

## 没有声音

先确认 TTS 总开关开着，并且只开了一种引擎。本地方案要 5000 端口起来，云端方案要 Key 和网络。

## 听不见我说话

先确认 ASR 总开关开着。本地方案要 1000 端口和麦克风权限，或者改用百度流式 ASR。

## 路径里有中文，报一堆错

把整个安装目录挪到纯英文路径，再重新打开 WebUI 和各个 bat。

## 显存不足装不了

安装器在可用显存低于约 5 GB 时会拦住。不勾 TTS，改用云端发音即可。

## 更新 bat 闪退

可能是没有 conda 环境 `my-neuro`。改用发行包自己的更新方式，或备份配置后换新压缩包，见 [更新](/deploy/update)。

## 功能配置里的「对话历史记忆」

界面上带着警告：当前版本可能导致 AI 复读混乱，新手先别勾。
