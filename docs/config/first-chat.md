# 第一次对话

确认清单：

1. WebUI 已打开，配置已保存
2. **功能配置**里选好了对话模型
3. 若要用语音：ASR 总开关开着，且本地 ASR 已启动 **或** 百度 ASR 已填
4. TTS 总开关开着，且只启用了一种发音方式
5. Live2D 主服务在跑，桌面上看得到角色

## 语音聊

对着麦克风说话。识别成功后角色会思考，再出声、出字幕。说话或 `Ctrl + G` 可打断。

![功能配置里打开 ASR / TTS](/images/first-chat-voice.png)

## 打字聊

1. 功能配置勾选 **文字输入框**
2. 保存并重启桌宠
3. 在输入框打字回车

![文字输入框开关](/images/first-chat-text.png)

## 混用检查：本地 ASR + 云端 TTS

| 项 | 期望 |
| --- | --- |
| 启动页 | 能看到 ASR 卡片并已启动；TTS 卡片可以没有 |
| 云端配置 | 恰好一种云端 TTS 为开 |
| 对话 | 你说话 → 本地识别文字 → LLM → 云厂商出声 |

![启动页：关注 ASR，不必强求 TTS](/images/mix-services-asr-not-tts.png)

## 失败时先看哪

- 没反应：ASR 没开 / 没权限用麦克风 / 未启用 ASR
- 有字没声：TTS 总开关关了，或云端 TTS 未填，或多种 TTS 冲突，或本地 5000 没起来
- 有声乱：优先级更高的 TTS 仍开着
- 模型报错：回到 LLM 配置检查 URL 是否带 `/v1`、模型名是否真实存在
- 桌宠闪退：看启动页日志和 `runtime.log`

![系统日志](/images/webui-logs.png)
