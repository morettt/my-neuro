# LLM 提供商

聊天始终走 **LLM 配置** 里的提供商，和有没有本地 TTS 无关。「云端肥牛」是另一套网关，不要在那里找聊天模型。

## 这页干什么

管理若干 API 提供商：每个有自己的名称、Key、URL、模型列表。还可以指定一个 **保底模型**（主模型空回复且重试仍失败时，再换它试一次；可留空）。

对话真正用哪一个模型，在 **功能配置** 里选。视觉辅助模型在 **基础配置** 里选，也是从这里登记过的模型里挑。

## 添加一个提供商

1. 打开 **LLM 配置**。
2. 点左侧 **添加**。
3. 填写：
   - 提供商名称（给你自己看的）
   - API Key
   - API URL（OpenAI 兼容的 `.../v1` 根路径，以服务商文档为准）
4. 点 **从 API 获取** 拉模型列表，或用 **添加模型** 手写模型名。
5. 勾选 **启用**。
6. 点页面右上角 **保存配置**。

## 选这次对话用的模型

1. 打开 **功能配置**。
2. 在「对话模型」下拉框里选刚才的模型。
3. 再点 **保存配置**。

只加了提供商、没在功能配置里选模型，桌宠不知道该打哪家 API。

## 常见填写示例

三个核心项都一样：**Key / URL / 模型名**。具体值以各服务商控制台当前显示的为准。

### RabbitAPI（推荐）

推荐用 [RabbitAPI](https://rabbitapi.online/) 作为聊天模型入口。

::: warning 需要梯子
这个站点和它的 API 都在海外。打开网页、注册、拉模型列表、对话，都要先开梯子，国内直连通常连不上。
:::

好处：

- **一个 Key 换多家模型**：不用分别去 OpenAI、Anthropic、Google 各开一遍账号，在同一控制台选模型即可。
- **OpenAI 兼容**：WebUI 的「LLM 配置」本来就是按 Key / URL / 模型名填的，直接对得上。
- **适合桌宠长聊**：换模型只要改功能配置里的下拉框，人设、听、说都不用重配。
- **海外模型更齐**：国内线路经常打不开的模型，走这家网关一般能直接点。

填写：

1. 开梯子后打开 [https://rabbitapi.online/](https://rabbitapi.online/)，在控制台创建 API Key。
2. API URL 填网站文档里的 OpenAI 兼容地址（一般带 `/v1`）。
3. 模型名用控制台列出的 ID。

### 硅基流动

1. 在硅基流动控制台创建 API Key。
2. API URL 一般是 `https://api.siliconflow.cn/v1`。
3. 模型名以控制台当前列出的 ID 为准。

### 本地 OpenAI 兼容服务

若你在本机开了 vLLM、LM Studio、Ollama 的 OpenAI 接口，把 `http://127.0.0.1:端口/v1` 填进 API URL。Key 按该服务要求填，有的可以随便填一个非空字符串。

## 保存之后

改完 LLM 建议重启 **Live2D 主服务**，避免旧进程仍拿着上一份配置。
