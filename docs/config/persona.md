# 人设

## 这页干什么

**人格设置** 管角色怎么说话：系统提示词（人设）、可选的记忆提示、以及情绪与动作相关的高级项。改完必须保存，并重启 Live2D 才会稳定生效。

![人格设置页](/images/webui-persona.png)

## 基本操作

1. 打开 **人格设置**。
2. 在人设文本框里写角色说明：名字、说话习惯、禁止事项、和用户的关系。
3. 需要长期记忆时，确认记忆系统服务能起来，并按界面说明打开记忆相关开关。
4. 保存。

人设会进入发给 LLM 的系统消息。写得越具体，角色越稳；写成长篇小说会占上下文。

## 和插件、广场的关系

部分插件会改提示词或往对话里塞工具说明。广场工具屋里的角色卡也可能覆盖人设。本页改完如果发现角色又变了，检查插件是否开启、是否刚从广场导入过配置。

## 备份

人设存在 `live-2d/config.json`（以及角色备份相关 JSON）。大改之前复制一份文件，或用界面里的备份功能（若当前版本提供）。
