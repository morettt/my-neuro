# 人设

## 这页干什么

**人格设置** 管角色怎么说话：系统提示词（人设）、可选的记忆提示，以及情绪和动作相关的高级项。改完点 **保存配置**，再重启 Live2D 才会稳定生效。

![人格设置页](/images/webui-persona.png)

## 基本操作

1. 打开 **人格设置**。
2. 在人设文本框里写角色说明：名字、说话习惯、禁止事项、和你的关系。
3. 需要长期记忆时，确认记忆系统服务能起来，再按界面说明打开记忆相关开关。
4. 点 **保存配置**。

人设会作为系统消息发给 LLM。写得越具体，角色越稳定；写成长篇小说则会占掉上下文。

## 和插件、广场的关系

有些插件会改提示词，或往对话里塞工具说明。广场工具屋里的角色卡也可能覆盖人设。如果改完发现角色又变了，检查一下插件开关，以及是不是刚从广场导入过配置。

## 备份

人设存在 `live-2d/config.json`，以及角色备份相关的 JSON 文件里。大改之前先复制一份，或用界面里的备份功能（如果当前版本提供）。
