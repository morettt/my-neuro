# 怎么听

「听」是把麦克风变成文字。总开关在 **功能配置** 的 **启用 ASR**（界面文案写成「本地语音识别」，实际是总开关）；具体引擎在本地服务或 **云端配置** 里选。

听和说互不影响。你可以本地识别、云端发音。

![功能配置全页](/images/webui-dialog-full.png)

## 先开总开关

1. 打开 **功能配置**。
2. 勾选 **启用 ASR**。
3. 需要按键说话时，勾选 PTT，点「更改按键」后按下你想用的键（默认常为 `V`）。
4. 点右上角 **保存配置**。

![PTT 按键说话](/images/webui-dialog-ptt.png)

关掉「启用 ASR」后，程序不会走语音识别；仍可用文字输入框聊天。

## 方案 A：本地 ASR

适用：安装器勾过 ASR，或目录里能跑 `1.ASR.bat`。

1. 保持「启用 ASR」。
2. **不要**同时勾选百度流式 ASR（新手只留一种听）。
3. 到 **启动** 页启动 **ASR 语音识别**，等状态点变绿。端口是 **1000**。
4. 也可以双击根目录 `1.ASR.bat`，效果同类。

![启动页中的 ASR 卡片](/images/webui-service-asr.png)

::: warning
「启动」页 **看不到** ASR 卡片时，当前安装没有把本地服务入口画出来（通常也没有本地 TTS 模型目录）。请改用百度流式 ASR，或换一份装了 ASR 组件的安装。
:::

![没有本地服务卡片时的启动页](/images/webui-cloud-services-hidden.png)

## 方案 B：百度流式 ASR

1. 打开 **云端配置**，点子页 **百度流式 ASR**。
2. 勾选启用，填 URL、AppID、API Key、DevPid（以百度智能云控制台为准）。
3. 保存。不需要本地 1000 端口。

![云端配置 · 百度流式 ASR](/images/webui-cloud-baidu-asr.png)

## 新版界面上没有的东西

Electron 程序里仍可能存在 SiliconFlow ASR 等配置字段，但 **新版 WebUI 云端页目前只有：云端肥牛、云端 TTS、阿里云 TTS、字节 TTS、百度流式 ASR**。不要在新版顶栏里找「硅基 ASR 开关」。

## 语音输入相关选项

都在 **功能配置**，改完保存并重启桌宠：

- **PTT 按键说话**：按住录音，松开识别
- **语音打断**：你说话时打断 AI 正在播的语音
- **文字输入框**：打字聊天

![语音打断开关](/images/webui-dialog-barge.png)
