# 控制面板一览

新版顶栏页签。装了本地 TTS 模型时是 10 项；没装时少一个「声音克隆」。

1. **启动** — 启停进程、看日志、一键启动 / 停止
2. **基础配置** — 视觉、MCP、Function Call 等
3. **功能配置** — 对话模型、ASR / TTS 总开关、PTT、文字输入框
4. **人格设置** — 人设与记忆相关提示
5. **LLM 配置** — 提供商、模型列表、保底模型
6. **云端配置** — 云端肥牛、云端 TTS、阿里云 TTS、字节 TTS、百度流式 ASR
7. **Live2D设置** — 皮套与动作
8. **声音克隆** — 仅装了本地 TTS 时出现
9. **广场工具屋** — 提示词 / 工具 / FC / 插件广场
10. **插件管理** — 启用、停用、配置插件

![顶栏页签一览](/images/webui-sidebar.png)

顶部还有保存配置、主题（角色 / 赛博）、经典版面、语言、文档链接（指向官网旧教程）、GitHub、检查更新。

![保存按钮与经典版面](/images/webui-header-controls.png)
