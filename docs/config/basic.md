# 基础配置

这一页管「聊天以外」的能力开关，和 LLM / 听 / 说并列。改完保存并重启桌宠。

![基础配置：视觉模型与 MCP](/images/webui-basic-highlight.png)

## 视觉（截图）

- 每次对话都截屏：适合需要模型看见桌面的场景，费 Token、费流量。
- 用 BERT 判断要不要截屏：需要 BERT 服务（安装器组件 + **启动** 页里的 BERT）。
- 视觉模型在下拉框里选，模型必须先在 **LLM 配置** 里登记过。

## MCP 与 Function Call

- **MCP**：让模型调用你配置的 MCP 工具。需要对应服务/插件就绪。
- **Function Call**：走程序内置工具协议。两者不要在没看懂工具列表时同时乱开，以免模型把回合花在工具调用上。

具体工具名单以当前安装的插件和 `live-2d` 工具配置为准。

## 其他常见项

基础配置里还有语言、翻译、字幕相关选项（以你屏幕上实际控件为准）。中文用户通常保持界面中文；TTS 语言与字幕语言不一致时，才会用到「字幕中文、音频外语」一类开关。

## 记忆

长期记忆依赖 **记忆系统** 服务（MemOS，端口 `8003`）。启动页里若能看到记忆系统，请在第一次对话前启动；第一次加载模型可能要等几分钟。

没有本地 TTS 模型时，记忆启动卡片可能被隐藏。桌宠是否仍会连 `8003` 以日志为准：连不上时对话仍可能进行，只是没有长期记忆。不要把「必须先开 MemOS 否则完全不能聊」写成死规定。
