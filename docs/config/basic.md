# 基础配置

这一页管「聊天以外」的能力开关，和 LLM、听、说并列。改完点 **保存配置**，再重启桌宠。

![基础配置：视觉模型与 MCP](/images/webui-basic-highlight.png)

## 视觉（截图）

- **每次对话都截屏**：适合需要模型看见桌面的场景，费 Token、费流量。
- **用 BERT 判断要不要截屏**：需要 BERT 服务，也就是安装器勾过 BERT，并在启动页把它启起来。
- **视觉模型**在下拉框里选，模型必须先在 [LLM 配置](/config/llm) 里登记过。

## MCP 与 Function Call

- **MCP**：让模型调用你配置的 MCP 工具，需要对应服务或插件就绪。
- **Function Call**：走程序内置的工具协议。

先确认当前有哪些工具可用，再决定开哪一个。两个都开时，模型容易把回合花在调用工具上。具体每个插件能干什么，看 [内置插件](/plugins/built-in) 和 [社区插件](/plugins/community)。

## 其他常见项

基础配置里还有语言、翻译、字幕相关选项，以你屏幕上实际的控件为准。中文用户通常保持界面中文；只有 TTS 语言和字幕语言不一致时，才会用到「字幕中文、音频外语」这类开关。

## 记忆

长期记忆依赖 **记忆系统** 服务（MemOS，端口 `8003`）。启动页上能看到它时，建议在第一次对话前启动，首次加载模型可能要等几分钟。

记忆系统连不上时，对话通常仍能进行，只是没有长期记忆。没装本地语音模型的安装里，这张卡片可能不显示，对照见 [介绍](/guide/introduction)。
