my-neuro 线上版本 · 使用教程

📦 线上安装包（WebUI 显示「云端」） 🏷️ v6.6 📅 2026-07-03

一篇写给普通用户的说明书——不用懂代码，跟着做就能和桌面上的 AI 伙伴聊起来。

这是什么？

my-neuro（肥牛） 是一个住在电脑桌面上的 AI 虚拟伙伴。你可以说话或打字跟它聊，它会做表情、出声回答，还能记住你说过的重要事情。

🎤

语音聊天

对着麦克风说话，它会听、想、答、念出来

⌨️

打字聊天

开启输入框后，键盘也能交流

🎭

Live2D 角色

看皮套做表情、做动作

🧠

记忆 & 插件

长期记忆、日记、直播等扩展能力

线上版 vs 本地完整版

线上版本本地完整版
语音合成走云端（阿里云等），不用显卡本地 GPT-SoVITS，需要显卡
安装体积更小更大（含 TTS 模型）
适合谁普通电脑、想省事的人有显卡、想完全离线的人
⚠️ 已弃用，请勿使用：
  • 全云端肥牛（云端配置 → 启动全云端）— 服务已下线
  • RAG 服务 / RAG.bat — 已不再维护

WebUI 里可能还能看到相关按钮，请忽略。长期记忆请用 MemOS 记忆系统。

第一次使用：三步走

第 1 步：打开控制面板

  1. 进入 live-2d 文件夹
  2. 双击 启动 WebUI 控制面板.bat
  3. 浏览器打开后，看到 「My Neuro - 控制中心（云端）」
浏览器没自动打开？看黑色窗口里的地址，复制到浏览器即可。

第 2 步：填好 API 密钥

线上版需要配两样东西：大模型（负责聊天）和 阿里云 TTS（负责说话）。

✨ 标准配置

大模型 + 阿里云 TTS

① 大模型（负责聊天）

  1. 控制面板 → LLM 配置 → 添加 API Key 和接口地址
  2. 对话配置 → 选择要用的对话模型

② 语音（负责说话）

  1. 云端配置 → 阿里云 TTS → 勾选启用
  2. 填入 API Key、模型名（cosyvoice-v3-flash）、声音 ID
  3. 点右上角 保存

语音详细步骤见 阿里云 TTS 部署教程。

注意： 同时只开一种 TTS。启用阿里云 TTS 后，请关闭「字节 TTS」和「云端 TTS（SiliconFlow）」，也不要勾选已弃用的「启动全云端」。

第 3 步：启动服务，见到肥牛

回到 服务控制 页签，按顺序启动（缺一不可）：

  1. 点 ASR 语音识别 → 启动，等状态变绿
  2. 点 记忆系统 → 启动，等状态变绿（首次可能较慢，需等待 Embedding 模型加载）
  3. 点 Live2D 主服务 → 启动
重要： 线上版 必须先启动记忆系统（MemOS API），桌宠才能正常运行。若按钮旁提示「等待 ASR / 记忆系统 端口响应」，说明前置服务尚未就绪，请继续等待或查看记忆日志。
关于「一键启动」： 会依次启动 ASR、TTS、记忆系统等。本地 TTS、RAG 报错可忽略，但 记忆系统必须成功启动 后再开桌宠。
不要启动： 本地 TTS、RAG（已弃用）。记忆管理网页（打开 WebUI）按需使用，不是开桌宠的必需项。

成功后，桌面上会出现 Live2D 角色——那就是肥牛 🐂

怎么跟肥牛聊天？

语音聊天（默认）

  1. 确保 ASR 已启动（或使用百度流式 ASR）
  2. 直接对着麦克风说话
  3. 肥牛听到后会思考、回答，并用语音念出来

打断说话： 按 Ctrl + G

按键说话（PTT）： 在对话配置里勾选「启用 PTT」，默认按住 V 说话，松开识别。

打字聊天

  1. 控制面板 → 对话配置
  2. 勾选「文字输入框（可打字交互）」
  3. 保存并重启桌宠
  4. 桌宠界面会出现输入框

常用快捷键

快捷键作用
Ctrl + G打断 AI 说话
Ctrl + T窗口置顶
Ctrl + M切换气泡显示
Ctrl + Q退出程序
按住 V按键说话（需开启 PTT）
Ctrl + Shift + 1~5触发预设动作
Ctrl + Shift + 6随机播放音乐
Ctrl + Shift + 0停止所有动作

控制面板各页签是干什么的？

页签干什么用
服务控制启动/停止桌宠、ASR、记忆等；看日志
基础配置视觉识图、工具开关
对话配置选对话模型、开打字框、语音打断
人格设置改 AI 性格、人设提示词
LLM 配置管理 API 密钥和模型列表
云端配置阿里云 TTS、百度 ASR 等（勿用已弃用的全云端肥牛）
Live2D 设置皮套位置、大小、表情动作
声音克隆本地 TTS 训练（线上版一般用不到）
广场下载提示词、工具、插件资源
插件管理开关各种扩展功能
改完任何配置，记得点右上角 「保存」，必要时重启桌宠。

插件：给肥牛加技能

本安装包预装 33 个插件，默认启用 7 个。

完整说明见 插件使用教程 — 含每个插件的配置项、工具列表和「怎么说」示例。

改完插件配置后，建议 重启桌宠 生效。

记忆系统（启动桌宠的前置条件）

线上版 必须启动 MemOS 记忆后端，桌宠才能正常运行。内置记忆插件默认开启，连接 http://127.0.0.1:8003。

启动记忆后端（必做）

  1. 服务控制 → 记忆系统 → 启动
  2. 等待状态变绿（首次加载 Embedding 模型，可能需要 1~3 分钟）
  3. 可查看 记忆日志 确认是否就绪
也可手动运行 4.MEMOS-API.bat，效果与 WebUI 启动相同。

记忆管理网页（可选）

需要查看、添加、搜索记忆时，在记忆后端已运行的前提下，点 打开 WebUI 或运行 5.MEMOS-WebUI.bat。这不是开桌宠的必需步骤。

常见问题

  • 检查云端配置 → 阿里云 TTS 是否启用且 Key 正确
  • 确认字节 TTS、云端 TTS 没有同时开着
  • 看服务控制里的 TTS 日志 / 桌宠日志
  • 参考 阿里云 TTS 教程
  • 确认 ASR 语音识别已启动（状态变绿）
  • 检查麦克风权限和是否被其他软件占用
  • 或在云端配置中启用百度流式 ASR 作为替代
  • 确认 记忆系统 和 ASR 都已启动且状态变绿
  • 首次启动记忆系统较慢，请查看 记忆日志 是否仍在加载
  • 记忆后端默认地址 http://127.0.0.1:8003，不要被防火墙拦截
