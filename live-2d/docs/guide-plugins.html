插件使用教程

📦 my-neuro v6.6 线上版 ⚙️ WebUI → 插件管理 🔗 插件广场 同步 6 个

线上安装包 live-2d/plugins 自带 33 个插件。其中 7 个默认启用；另 6 个与插件广场同步。下文逐一说明怎么配、怎么用。

概述

插件是肥牛的「技能模块」。启用后 AI 会通过 Function Call 或自动逻辑使用相关能力。

前提： WebUI → 基础配置 → 开启 启用 Function Call 工具。记忆类插件需先启动 MemOS 记忆系统。

默认启用见 enabled_plugins.json（7 个）。全文覆盖本安装包全部 33 个预装插件；标「插件广场」的可在 mynewbot.com/plugin-hub 查看仓库。

如何管理插件

  1. WebUI → 插件管理
  2. 内置 / 社区页签中找到插件
  3. 开关 启用 / 关闭，点 配置 改参数
  4. 保存后 重启 Live2D 桌宠
改配置后务必重启桌宠。MemOS 相关改动可能还需重启记忆系统。

MemOS 长期记忆 内置

最核心的插件。负责让肥牛记住跨天、跨重启的对话。线上版必须先启动 MemOS 后端，桌宠才能正常运行。

你能感受到什么

  • 聊过的事过几天还能被提起（自动检索注入）
  • 对话会自动写入长期记忆（默认每 5 轮批量保存）
  • 可对 AI 说「帮我记住……」，它会调用记忆工具

必做配置

配置项建议
启用 MemOS保持开启
MemOS API 地址http://127.0.0.1:8003
自动注入记忆建议开启
自动保存对话建议开启
后端 LLM用于记忆总结/实体提取，可与对话模型相同或更便宜的模型

AI 可用工具（12 个）

memos_search_memory memos_add_memory memos_upload_image memos_search_images memos_save_screenshot memos_import_url memos_import_document memos_correct_memory memos_get_preferences …

怎么说 / 怎么用

  • 「你还记得我上次说的那件事吗？」— 自动检索记忆
  • 「把这个记一下：我周五一般不加班」— AI 会写入记忆
  • 「帮我搜一下记忆里关于 XX 的内容」— 调用搜索工具

详细记忆管理见 使用教程 · 记忆系统，后端说明见插件内「📖 配置说明」。

思痕之册 内置

帮肥牛把一天的对话凝结成观察日志，并可按月生成月度总结，部分摘要会写入核心记忆。

日志保存位置

默认：live-2d/AI记录室/AI日志/{日期}-AI日志.txt

月度总结：{年月}-月度总结.txt

AI 可用工具

write_ai_diary read_recent_diary write_monthly_summary

怎么说

  • 「帮我写今天的 AI 日志」— 明确要求时触发
  • 晚上说「晚安，我去睡了」— 在设定时间段内可自动触发写日志
  • 「读一下最近三天的日志」
插件不会在未经你同意时偷偷写日志；晚安触发也需在当前消息里明确出现睡觉相关词语。

晨昏之线 社区

让肥牛感知当前时间、星期、中国节假日/调休、上午/下午/晚上，并在设定整点主动问候。

首次使用

在插件目录执行一次依赖安装（节假日数据需要）：

powershell 
cd live-2d\plugins\community\dawn-dusk-line
npm install

主要配置

配置项默认 / 说明
感知与时钟时区Asia/Shanghai
注入环境感知到 LLM每次对话附带时间/工作日/时段前缀
问候整点时刻0,8,12,18（午夜/早/午/傍晚）
静默判定阈值超过 10 分钟无交互会主动问候

AI 可用工具

dawn_dusk_get_time dawn_dusk_greeting_check

你能感受到什么

  • 肥牛更知道「现在几点、是不是周末、是不是法定节假日」
  • 在 0/8/12/18 点等时刻可能主动说早安、提醒吃饭、问今天过得怎样
  • 你正在聊天时，整点问候会改成「注入提示」而不是硬打断

核心记忆注入 社区

比 MemOS 更「硬」的一层记忆：每次对话都会把文件内容完整注入系统提示词，适合放绝对不能忘的信息。

记忆文件位置

live-2d/AI记录室/核心用户记忆.txt

文件不存在时插件会跳过；你可以用记事本直接编辑，保存后约 1 秒自动重载。

AI 可用工具

core_memory_write core_memory_list

怎么说

  • 「写入核心记忆：我叫小明，讨厌被叫全名」
  • 「这个要永远记住：我对花生过敏」
  • 「看看核心记忆里有什么」
与 MemOS 的区别： 核心记忆是文本文件、每次全量加载、优先级最高；MemOS 是向量检索、按需召回、容量更大。

代码执行 内置

允许 AI 在本地 conda 环境 my-neuro 中运行 Python 代码，用于计算、数据处理、文件操作等。

AI 可用工具

execute_code install_packages

怎么说

  • 「用 Python 算一下 123456 的平方根」
  • 「帮我把桌面某个 txt 文件里的重复行去掉」
  • 「需要的话你可以写代码跑一下」
安全提示： 代码会在你电脑上真实执行。只在你信任的场景下让 AI 跑代码；涉及删除文件、网络请求等操作请留意 AI 的具体代码内容。

网络搜索 内置

让肥牛能查互联网上的最新信息，基于 Tavily 搜索 API。

必配项

插件配置 → Tavily API Key

前往 tavily.com 注册获取。未填写 Key 时，搜索工具不会注册，AI 无法联网搜索。

AI 可用工具

web_search

怎么说

  • 「搜一下今天 XX 的新闻」
  • 「帮我查一下 Python 3.13 有什么新特性」
  • 「这个我不确定，你去网上查查」

每次搜索返回 AI 摘要 + 若干条结果链接与片段。

用户画像 社区

从长期记忆和近期对话中保守地归纳你的画像（习惯、偏好、性格观察等），并在每次对话前注入。

工作方式

  • AI记录室/用户画像.json — 正式画像，会注入提示词
  • AI记录室/用户画像_候选.json — 候选观察，不注入，用于跨天累积证据
  • 同一习惯需多个不同日期佐证才会「晋升」为正式画像（防误判）
  • 首次启动会尝试从 MemOS 拉取数据做初始诊断

主要配置

配置项说明
注入用户画像是否每次对话注入正式画像
专用画像模型 profile_llm可单独配 API，留空则用主对话模型
晋升门槛 promote_count / promote_span_days候选升级为正式画像的条件

AI 可用工具

profile_view profile_update profile_rebuild

怎么说

  • 「你现在对我的印象是什么？」— 查看画像
  • 「我习惯晚上写代码，这个记进画像」— 强信号可快速晋升
  • 「重新从我的记忆里诊断一下画像」— 调用 rebuild

看视频 社区

live-2d/plugins/community/watch-screen

实时截图，保留最近5帧上下文。被动：每次用户说话时自动把最新屏幕注入LLM。主动：定时观察屏幕，有趣时自主评论。

怎么用

  • WebUI → 插件管理 → 启用/配置

插件协作关系

MemOS 后端（必启）→ 长期记忆 / 用户画像 / AI 日志
↓
核心记忆.txt + 思痕之册 + 晨昏之线 → 注入上下文
↓
网络搜索 / 代码执行 → 按需扩展
↓
心情对话 / 定时问候 / 自动聊天 → 主动陪伴（按需启用）

默认 7 个插件已覆盖记忆、搜索、代码、时间感知。其余 26 个预装插件按需启用，避免同类主动对话插件同时开太多。

常见问题

保存后重启 Live2D 主服务。MemOS 后端 LLM 改动还需重启记忆系统。

安装包预装了 33 个插件，默认只开 7 个。其余在插件管理里手动启用即可，本文一并说明。

确认「网络搜索」已启用且填写 Tavily API Key。

WebUI → 广场 或 插件广场 下载。本文已覆盖本包自带的 33 个。
