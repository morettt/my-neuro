# PMX 模型

每个模型放在独立文件夹中，文件夹名就是控制面板中的模型名：

```text
3D/PMX/
└── 少女大肥鱼/
    ├── ds娘.pmx
    └── textures/
```

保留模型自带贴图与其相对路径。添加后重新打开控制面板，
在“当前桌宠”中选择 `[PMX] 少女大肥鱼`。

支持左键拖动、滚轮缩放、右键旋转视角、Alt + 滚轮调整相机距离，
以及 TTS 和歌曲人声音频驱动口型。开口表情支持标准 MMD 的 `あ`、`お`、`う`
及常见英文名称；没有对应表情的模型会提示口型不可用。

内部配置形态名为 `mmd`，选择路径保存在 `ui.mmd_model_path`。
每个文件夹识别一个模型；存在多个 PMX 文件时使用相对路径排序后的第一份。
此适配包含基础待机和眨眼，尚未接入 MMD 物理模拟和 VMD 动作播放。
